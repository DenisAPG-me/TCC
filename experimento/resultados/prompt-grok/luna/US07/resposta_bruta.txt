CASOS DE TESTE

| ID | Título | Tipo | Critério de Aceitação Relacionado | Passos Resumidos | Resultado Esperado |
|----|--------|------|-----------------------------------|------------------|--------------------|
| TC01 | Criar reserva com dados válidos | positivo | 1 | Enviar um corpo JSON válido para criar reserva. | Status 200; resposta contém identificador numérico e os mesmos dados enviados. |
| TC02 | Consultar reserva recém-criada | positivo | 2 | Criar reserva e consultar pelo identificador retornado. | Status 200; todos os campos correspondem aos dados enviados. |
| TC03 | Consultar identificador inexistente | negativo | 3 | Consultar o identificador `99999999`. | Status 404. |
| TC04 | Listar reserva por nome e sobrenome únicos | positivo | 4 | Criar reserva com nome e sobrenome únicos; listar usando ambos como filtros. | A lista contém o identificador da reserva criada. |

SUPOSIÇÕES

- A API usa `POST /booking` para criar, `GET /booking/{id}` para consultar e `GET /booking?firstname=...&lastname=...` para filtrar reservas.
- Os corpos e campos seguem o formato esperado pelo serviço: `firstname`, `lastname`, `totalprice`, `depositpaid`, `bookingdates` (`checkin`, `checkout`) e `additionalneeds`.
- O identificador retornado é disponibilizado em `bookingid`, e a resposta da criação contém `booking`.
- Datas válidas são representadas como `YYYY-MM-DD`; o check-out ocorre depois do check-in.
- A API está disponível na URL base fornecida e não exige autenticação para essas operações.
- Cada teste cria sua própria reserva; para o filtro, o nome e sobrenome incluem um sufixo aleatório para reduzir colisões.
- Não foram especificados casos de rejeição de campos inválidos; os casos negativos limitam-se ao identificador inexistente descrito na história.

```python
import uuid

import pytest
import requests


BASE_URL = "https://restful-booker.herokuapp.com"


def _booking_payload(firstname=None, lastname=None):
    suffix = uuid.uuid4().hex[:10]
    return {
        "firstname": firstname or f"Teste{suffix}",
        "lastname": lastname or f"Reserva{suffix}",
        "totalprice": 123,
        "depositpaid": True,
        "bookingdates": {
            "checkin": "2027-01-10",
            "checkout": "2027-01-15",
        },
        "additionalneeds": "Café da manhã",
    }


def _create_booking(payload):
    response = requests.post(
        f"{BASE_URL}/booking",
        json=payload,
        headers={"Accept": "application/json"},
        timeout=30,
    )
    return response


def test_TC01_criar_reserva_com_dados_validos():
    payload = _booking_payload()

    response = _create_booking(payload)

    assert response.status_code == 200
    body = response.json()
    assert isinstance(body.get("bookingid"), int)
    assert body.get("booking") == payload


def test_TC02_consultar_reserva_recém_criada():
    payload = _booking_payload()
    create_response = _create_booking(payload)

    assert create_response.status_code == 200
    booking_id = create_response.json().get("bookingid")
    assert isinstance(booking_id, int)

    response = requests.get(
        f"{BASE_URL}/booking/{booking_id}",
        headers={"Accept": "application/json"},
        timeout=30,
    )

    assert response.status_code == 200
    assert response.json() == payload


def test_TC03_consultar_identificador_inexistente():
    response = requests.get(
        f"{BASE_URL}/booking/99999999",
        headers={"Accept": "application/json"},
        timeout=30,
    )

    assert response.status_code == 404


def test_TC04_listar_reserva_por_nome_e_sobrenome_unicos():
    payload = _booking_payload()
    create_response = _create_booking(payload)

    assert create_response.status_code == 200
    booking_id = create_response.json().get("bookingid")
    assert isinstance(booking_id, int)

    response = requests.get(
        f"{BASE_URL}/booking",
        params={
            "firstname": payload["firstname"],
            "lastname": payload["lastname"],
        },
        timeout=30,
    )

    assert response.status_code == 200
    booking_ids = response.json()
    assert isinstance(booking_ids, list)
    assert any(
        isinstance(item, dict) and item.get("bookingid") == booking_id
        for item in booking_ids
    )
```

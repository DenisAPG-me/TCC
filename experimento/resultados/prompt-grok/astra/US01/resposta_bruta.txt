|----|--------|------|-----------------------------------|------------------|--------------------|

| TC05 | Buscar parte de uma palavra | borda | 1 — extensão assumida | Abrir a página inicial; pesquisar “ham”. | Há produtos; todos os nomes contêm “ham”; a página identifica o termo pesquisado. |
| TC06 | Buscar pelo nome completo de um produto | borda | 1 — extensão assumida | Obter um nome completo nos resultados de “hammer”; voltar à página inicial; pesquisar esse nome. | O produto aparece; todos os resultados contêm o nome pesquisado; a página identifica o termo. |

SUPOSIÇÕES

- Nenhuma informação externa foi consultada. O código é uma implementação hipotética, não executada nem validada contra o sistema real.
- A interface é web. Utilizam-se Python, pytest, Playwright síncrono e o plugin oficial `pytest-playwright`, exigido pelos requisitos técnicos, além da biblioteca padrão do Python.
- Salvar como `test_busca_ordenacao.py`. Preparação: `pip install pytest playwright pytest-playwright` e `playwright install chromium`. Execução: `pytest test_busca_ordenacao.py`.
- A página inicial está em `/`, relativa à constante `BASE_URL`. Não são necessários login, consentimento ou outra preparação.
- Cada teste recebe uma página isolada pela fixture oficial `page`.
- Todos os seletores são suposições centralizadas no código: campo com rótulo acessível `Search`, botão `Search`, seletor HTML nativo com rótulo `Sort`, contêiner `data-testid="product-list"`, cartões `product-card`, nomes `product-name`, preços `product-price`, indicação da busca `search-term` e mensagem vazia `empty-state`.
- As opções de ordenação possuem valores `price,asc` e `name,desc`.
- Para sincronizar atualizações, assume-se que o contêiner persiste mesmo vazio, possui `aria-busy="false"` quando pronto e registra `data-applied-search` e `data-applied-sort` **somente quando os resultados correspondentes foram integralmente renderizados**. Esses atributos são contratos hipotéticos que precisam ser adaptados à interface real.
- Na carga inicial, `data-applied-search=""` e `data-applied-sort="default"`. A ordenação padrão difere das opções testadas.
- O indicador `search-term` contém exclusivamente o termo pesquisado. A mensagem vazia usa exatamente o texto do critério 2.
- O catálogo contém pelo menos um produto com “hammer” no nome e pelo menos dois produtos na página inicial. “zzzzxx” não corresponde a nenhum produto.
- A busca corresponde a substrings do nome, sem diferenciar maiúsculas de minúsculas. Buscar “ham” e buscar um nome completo são extensões assumidas do comportamento por palavra-chave; esses detalhes não estão explicitamente definidos na User Story.
- O catálogo permanece estável durante cada teste. TC06 obtém seu dado dinamicamente e não exige nomes únicos.
- Cada cartão contém exatamente um nome não vazio e um preço não negativo, em dólares, no formato `$12.34` ou `$1,234.56`. Os preços são comparados numericamente com `Decimal`.
- A ordenação alfabética usa comparação de nomes sem distinção de caixa, após normalizar espaços. Assume-se que não existem regras especiais de idioma que alterem essa comparação.
- Empates são válidos; não se exige um critério secundário de ordenação.
- As verificações abrangem somente os cartões da página atual. Não se presume comportamento entre páginas, quantidade exata de resultados ou preservação de paginação.
- Entrada vazia, espaços, acentos, caracteres especiais e combinação de busca com ordenação não possuem resultado definido nos critérios e não são tratados como requisitos adicionais.

```python
import re
from decimal import Decimal

from playwright.sync_api import Page, expect


BASE_URL = "https://practicesoftwaretesting.com/"
TIMEOUT_MS = 15_000

SEARCH_LABEL = "Search"
SEARCH_BUTTON = "Search"
SORT_LABEL = "Sort"

LIST_ID = "product-list"
CARD_ID = "product-card"
NAME_ID = "product-name"
PRICE_ID = "product-price"
SEARCH_TERM_ID = "search-term"
EMPTY_STATE_ID = "empty-state"

PRICE_ASC = "price,asc"
NAME_DESC = "name,desc"

expect.set_options(timeout=TIMEOUT_MS)


def normalize_text(value: str) -> str:
    return " ".join(value.split())


def normalized_literal_pattern(value: str) -> re.Pattern:
    """Permite diferenças de espaços, preservando o texto e sua caixa."""
    words = normalize_text(value).split(" ")
    body = r"\s+".join(re.escape(word) for word in words)
    return re.compile(r"^\s*" + body + r"\s*$")


def results(page: Page):
    return page.get_by_test_id(LIST_ID)


def cards(page: Page):
    return results(page).get_by_test_id(CARD_ID)


def names(page: Page):
    return cards(page).get_by_test_id(NAME_ID)


def prices(page: Page):
    return cards(page).get_by_test_id(PRICE_ID)


def wait_for_results(
    page: Page,
    search_term: str,
    sort_value: str,
) -> None:
    # Contrato hipotético: atributos aplicados só mudam após renderização.
    listing = results(page)
    expect(listing).to_be_visible()
    expect(listing).to_have_attribute("data-applied-search", search_term)
    expect(listing).to_have_attribute("data-applied-sort", sort_value)
    expect(listing).to_have_attribute("aria-busy", "false")


def open_home(page: Page) -> None:
    page.goto(f"{BASE_URL.rstrip('/')}/")
    expect(page.get_by_label(SEARCH_LABEL, exact=True)).to_be_visible()
    wait_for_results(page, search_term="", sort_value="default")
    expect(cards(page).first).to_be_visible()


def search(page: Page, term: str) -> None:
    page.get_by_label(SEARCH_LABEL, exact=True).fill(term)
    page.get_by_role("button", name=SEARCH_BUTTON, exact=True).click()
    wait_for_results(page, search_term=term, sort_value="default")


def check_search_indicator(page: Page, term: str) -> None:
    indicator = page.get_by_test_id(SEARCH_TERM_ID)
    expect(indicator).to_be_visible()
    expect(indicator).to_have_text(term)


def check_matching_products(page: Page, term: str) -> None:
    check_search_indicator(page, term)
    expect(cards(page).first).to_be_visible()

    product_count = cards(page).count()
    expect(names(page)).to_have_count(product_count)

    pattern = re.compile(re.escape(term), re.IGNORECASE)
    for index in range(product_count):
        card = cards(page).nth(index)
        name = card.get_by_test_id(NAME_ID)
        expect(card).to_be_visible()
        expect(name).to_be_visible()
        expect(name).to_contain_text(pattern)


def select_sort(page: Page, value: str) -> None:
    # Evita que a verificação de ordem passe com apenas zero ou um produto.
    expect(cards(page).nth(1)).to_be_visible()

    select = page.get_by_label(SORT_LABEL, exact=True)
    expect(select).to_be_visible()
    select.select_option(value)
    expect(select).to_have_value(value)

    wait_for_results(page, search_term="", sort_value=value)
    expect(cards(page).nth(1)).to_be_visible()


def price_to_decimal(text: str) -> Decimal:
    # O formato já é validado com expect antes desta conversão.
    normalized = normalize_text(text)
    numeric = normalized.replace("$", "").replace(",", "").strip()
    return Decimal(numeric)


def test_TC01_buscar_hammer(page: Page) -> None:
    open_home(page)
    search(page, "hammer")
    check_matching_products(page, "hammer")


def test_TC02_buscar_termo_inexistente(page: Page) -> None:
    open_home(page)
    search(page, "zzzzxx")

    message = page.get_by_test_id(EMPTY_STATE_ID)
    expect(message).to_be_visible()
    expect(message).to_have_text("There are no products found.")
    expect(cards(page)).to_have_count(0)


def test_TC03_ordenar_precos_crescentes(page: Page) -> None:
    open_home(page)
    select_sort(page, PRICE_ASC)

    price_locator = prices(page)
    product_count = cards(page).count()
    expect(price_locator).to_have_count(product_count)

    price_pattern = re.compile(
        r"^\s*\$\s*(?:\d+|\d{1,3}(?:,\d{3})+)\.\d{2}\s*$"
    )
    for index in range(product_count):
        expect(cards(page).nth(index)).to_be_visible()
        expect(price_locator.nth(index)).to_be_visible()
        expect(price_locator.nth(index)).to_have_text(price_pattern)

    displayed_prices = [
        normalize_text(text) for text in price_locator.all_text_contents()
    ]
    expected_prices = sorted(displayed_prices, key=price_to_decimal)

    # Compara a sequência inteira, usando valores numéricos como chave.
    expect(price_locator).to_have_text(
        [normalized_literal_pattern(text) for text in expected_prices]
    )


def test_TC04_ordenar_nomes_de_z_a_a(page: Page) -> None:
    open_home(page)
    select_sort(page, NAME_DESC)

    name_locator = names(page)
    product_count = cards(page).count()
    expect(name_locator).to_have_count(product_count)

    for index in range(product_count):
        expect(cards(page).nth(index)).to_be_visible()
        expect(name_locator.nth(index)).to_be_visible()
        expect(name_locator.nth(index)).to_have_text(re.compile(r"\S"))

    displayed_names = [
        normalize_text(text) for text in name_locator.all_text_contents()
    ]
    expected_names = sorted(
        displayed_names,
        key=str.casefold,
        reverse=True,
    )

    expect(name_locator).to_have_text(
        [normalized_literal_pattern(text) for text in expected_names]
    )


def test_TC05_buscar_parte_da_palavra(page: Page) -> None:
    open_home(page)
    search(page, "ham")
    check_matching_products(page, "ham")


def test_TC06_buscar_nome_completo(page: Page) -> None:
    open_home(page)
    search(page, "hammer")
    check_matching_products(page, "hammer")

    full_name = normalize_text(names(page).first.inner_text())

    open_home(page)
    search(page, full_name)
    check_matching_products(page, full_name)

    exact_name = names(page).filter(
        has_text=normalized_literal_pattern(full_name)
    )
    expect(exact_name.first).to_be_visible()
```

CASOS DE TESTE

| ID | Título | Tipo | Critério de Aceitação Relacionado | Passos Resumidos | Resultado Esperado |
|----|--------|------|-----------------------------------|------------------|--------------------|
| TC01 | Criar reserva com dados válidos | positivo | Critério 1 | Enviar requisição POST para `/booking` com um JSON válido contendo nome, sobrenome, preço total, depósito pago, datas e necessidades adicionais. | Status 200, ID numérico retornado e dados correspondentes aos enviados. |
| TC02 | Consultar reserva existente pelo ID | positivo | Critério 2 | Criar uma reserva, obter o ID retornado e enviar requisição GET para `/booking/{id}`. | Status 200 e todos os campos retornados iguais aos enviados na criação. |
| TC03 | Consultar reserva com identificador inexistente | negativo | Critério 3 | Enviar requisição GET para `/booking/99999999`. | Status 404 (Not Found). |
| TC04 | Listar e filtrar reservas por nome e sobrenome únicos | positivo | Critério 4 | Criar uma reserva com nome e sobrenome únicos, depois enviar requisição GET para `/booking` passando os parâmetros de busca `firstname` e `lastname`. | Status 200 e a lista contém o identificador da reserva criada. |

SUPOSIÇÕES

- A URL base utilizada é `https://restful-booker.herokuapp.com`.
- O endpoint para criar e listar reservas é `/booking` e para consultar uma reserva específica é `/booking/{id}`.
- O formato do corpo JSON para criação de reservas segue a estrutura padrão da API Restful Booker: `{"firstname": "...", "lastname": "...", "totalprice": 100, "depositpaid": true, "bookingdates": {"checkin": "2026-01-01", "checkout": "2026-01-02"}, "additionalneeds": "Breakfast"}`.
- O filtro por nome e sobrenome na listagem é feito através dos parâmetros de consulta `firstname` e `lastname` na URL `/booking`.
- O identificador numérico retornado na criação da reserva está presente na propriedade `bookingid` da resposta JSON.

```python
import pytest
import requests

BASE_URL = "https://restful-booker.herokuapp.com"

@pytest.fixture
def booking_payload():
    return {
        "firstname": "John",
        "lastname": "DoeTest",
        "totalprice": 150,
        "depositpaid": True,
        "bookingdates": {
            "checkin": "2026-06-01",
            "checkout": "2026-06-10"
        },
        "additionalneeds": "Lunch"
    }

def test_TC01_criar_reserva_valida(booking_payload):
    response = requests.post(f"{BASE_URL}/booking", json=booking_payload)
    assert response.status_code == 200
    data = response.json()
    assert "bookingid" in data
    assert isinstance(data["bookingid"], int)
    
    created_booking = data["booking"]
    assert created_booking["firstname"] == booking_payload["firstname"]
    assert created_booking["lastname"] == booking_payload["lastname"]
    assert created_booking["totalprice"] == booking_payload["totalprice"]
    assert created_booking["depositpaid"] == booking_payload["depositpaid"]
    assert created_booking["bookingdates"] == booking_payload["bookingdates"]
    assert created_booking["additionalneeds"] == booking_payload["additionalneeds"]

def test_TC02_consultar_reserva_existente(booking_payload):
    post_response = requests.post(f"{BASE_URL}/booking", json=booking_payload)
    assert post_response.status_code == 200
    booking_id = post_response.json()["bookingid"]

    get_response = requests.get(f"{BASE_URL}/booking/{booking_id}")
    assert get_response.status_code == 200
    data = get_response.json()

    assert data["firstname"] == booking_payload["firstname"]
    assert data["lastname"] == booking_payload["lastname"]
    assert data["totalprice"] == booking_payload["totalprice"]
    assert data["depositpaid"] == booking_payload["depositpaid"]
    assert data["bookingdates"] == booking_payload["bookingdates"]
    assert data["additionalneeds"] == booking_payload["additionalneeds"]

def test_TC03_consultar_reserva_inexistente():
    response = requests.get(f"{BASE_URL}/booking/99999999")
    assert response.status_code == 404

def test_TC04_listar_reservas_filtrando_por_nome():
    unique_payload = {
        "firstname": "UniqueNameX",
        "lastname": "UniqueLastNameY",
        "totalprice": 200,
        "depositpaid": False,
        "bookingdates": {
            "checkin": "2026-07-01",
            "checkout": "2026-07-05"
        },
        "additionalneeds": "Dinner"
    }
    post_response = requests.post(f"{BASE_URL}/booking", json=unique_payload)
    assert post_response.status_code == 200
    booking_id = post_response.json()["bookingid"]

    params = {
        "firstname": unique_payload["firstname"],
        "lastname": unique_payload["lastname"]
    }
    get_response = requests.get(f"{BASE_URL}/booking", params=params)
    assert get_response.status_code == 200
    
    bookings_list = get_response.json()
    ids = [item.get("bookingid") for item in bookings_list]
    assert booking_id in ids
```

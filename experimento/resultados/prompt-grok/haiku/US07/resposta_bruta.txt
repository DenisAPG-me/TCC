CASOS DE TESTE

| ID | Título | Tipo | Critério de Aceitação Relacionado | Passos Resumidos | Resultado Esperado |
|----|--------|------|-----------------------------------|------------------|--------------------|
| TC01 | Criar reserva com dados válidos | positivo | AC1 | POST `/booking` com payload completo | Status 200; `bookingid` numérico (int); `booking` idêntico ao payload enviado |
| TC02 | Consultar reserva criada pelo identificador | positivo | AC2 | Criar reserva (fixture); GET `/booking/{bookingid}` | Status 200; corpo idêntico ao payload enviado |
| TC03 | Consultar identificador inexistente (99999999) | negativo | AC3 | GET `/booking/99999999` | Status 404 |
| TC04 | Listar por nome e sobrenome únicos inclui o identificador criado | positivo | AC4 | Criar reserva; GET `/booking?firstname=...&lastname=...` | Status 200; lista contém o `bookingid` criado |
| TC05 | Consultar identificador zero (borda do intervalo) | borda | AC3 | GET `/booking/0` | Status 404 |
| TC06 | Criar reserva com valores de borda (preço 0, depósito não pago, check-in igual ao check-out) | borda | AC1 | POST `/booking` com `totalprice=0`, `depositpaid=false`, `checkin=checkout` | Status 200; `booking` idêntico ao payload enviado |
| TC07 | Listar por nome e sobrenome inexistentes | negativo | AC4 | GET `/booking?firstname=...&lastname=...` com nomes aleatórios não cadastrados | Status 200; lista vazia |
| TC08 | Criar reserva com corpo JSON malformado | negativo | AC1 | POST `/booking` com corpo `{invalido` e `Content-Type: application/json` | Status 4xx ou 5xx (≥ 400); nenhum `bookingid` retornado |

SUPOSIÇÕES

- Endpoints: `POST /booking`, `GET /booking/{id}` e `GET /booking?firstname=&lastname=` sob a URL base `https://restful-booker.herokuapp.com`.
- A resposta de criação tem o formato `{"bookingid": <int>, "booking": {...}}`, e o objeto `booking` contém exatamente as chaves enviadas: `firstname`, `lastname`, `totalprice`, `depositpaid`, `bookingdates` (`checkin`, `checkout`) e `additionalneeds`.
- Datas no formato `YYYY-MM-DD`; `totalprice` inteiro; `depositpaid` booleano.
- Criar e consultar reservas não exige autenticação. Não há teardown, pois a remoção exigiria token; as reservas de teste são isoladas por nomes únicos gerados com UUID.
- Consulta a um identificador inexistente retorna 404, independentemente do corpo da resposta.
- Identificador `0` não existe na base, portanto retorna 404 (assumido).
- Check-in igual ao check-out é aceito pela API (assumido) em TC06.
- Corpo JSON malformado é rejeitado com erro 4xx ou 5xx; o teste exige apenas `status >= 400` por não se conhecer o código exato.
- Listagem por nome sem correspondência retorna 200 com lista vazia (não 404).
- A API pública pode estar indisponível ou com dados alterados por outros usuários; o teste de listagem depende de nomes gerados com UUID para evitar colisões.
- Timeout de requisição: 15 segundos.

```python
import uuid

import pytest
import requests

BASE_URL = "https://restful-booker.herokuapp.com"
TIMEOUT = 15


def build_payload(**overrides):
    payload = {
        "firstname": f"Ana{uuid.uuid4().hex[:8]}",
        "lastname": f"Silva{uuid.uuid4().hex[:8]}",
        "totalprice": 150,
        "depositpaid": True,
        "bookingdates": {"checkin": "2026-01-10", "checkout": "2026-01-15"},
        "additionalneeds": "Café da manhã",
    }
    payload.update(overrides)
    return payload


def create_booking(payload):
    return requests.post(f"{BASE_URL}/booking", json=payload, timeout=TIMEOUT)


def get_booking(booking_id):
    return requests.get(f"{BASE_URL}/booking/{booking_id}", timeout=TIMEOUT)


def search_bookings(firstname, lastname):
    return requests.get(
        f"{BASE_URL}/booking",
        params={"firstname": firstname, "lastname": lastname},
        timeout=TIMEOUT,
    )


@pytest.fixture
def created_booking():
    payload = build_payload()
    response = create_booking(payload)
    assert response.status_code == 200
    return response.json()["bookingid"], payload


def test_TC01_criar_reserva_com_dados_validos_retorna_200_e_dados_iguais():
    payload = build_payload()

    response = create_booking(payload)

    assert response.status_code == 200
    body = response.json()
    assert isinstance(body["bookingid"], int)
    assert body["booking"] == payload


def test_TC02_consultar_reserva_criada_retorna_200_e_campos_iguais(created_booking):
    booking_id, payload = created_booking

    response = get_booking(booking_id)

    assert response.status_code == 200
    assert response.json() == payload


def test_TC03_consultar_identificador_inexistente_retorna_404():
    response = get_booking(99999999)

    assert response.status_code == 404


def test_TC04_listar_por_nome_e_sobrenome_inclui_identificador_criado(created_booking):
    booking_id, payload = created_booking

    response = search_bookings(payload["firstname"], payload["lastname"])

    assert response.status_code == 200
    booking_ids = [item["bookingid"] for item in response.json()]
    assert booking_id in booking_ids


def test_TC05_consultar_identificador_zero_retorna_404():
    response = get_booking(0)

    assert response.status_code == 404


def test_TC06_criar_reserva_com_valores_de_borda_retorna_200_e_dados_iguais():
    payload = build_payload(
        totalprice=0,
        depositpaid=False,
        bookingdates={"checkin": "2026-01-10", "checkout": "2026-01-10"},
    )

    response = create_booking(payload)

    assert response.status_code == 200
    assert response.json()["booking"] == payload


def test_TC07_listar_por_nome_inexistente_retorna_lista_vazia():
    response = search_bookings(f"Inexistente{uuid.uuid4().hex}", f"Fantasma{uuid.uuid4().hex}")

    assert response.status_code == 200
    assert response.json() == []


def test_TC08_criar_reserva_com_json_malformado_retorna_erro():
    response = requests.post(
        f"{BASE_URL}/booking",
        data="{invalido",
        headers={"Content-Type": "application/json"},
        timeout=TIMEOUT,
    )

    assert response.status_code >= 400
    assert "bookingid" not in response.text
```

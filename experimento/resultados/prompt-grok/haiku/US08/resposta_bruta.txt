CASOS DE TESTE

| ID | Título | Tipo | Critério de Aceitação Relacionado | Passos Resumidos | Resultado Esperado |
|----|--------|------|-----------------------------------|------------------|--------------------|
| TC01 | Autenticar com credenciais válidas | positivo | AC1 | POST /auth com `admin` / `password123` | Status 200 e campo `token` não vazio |
| TC02 | Autenticar com senha inválida | negativo | AC2 | POST /auth com `admin` / senha errada | Sem campo `token` e `reason` = "Bad credentials" |
| TC03 | Senha com caixa diferente não autentica | borda | AC2 | POST /auth com `admin` / `PASSWORD123` | Sem campo `token` e `reason` = "Bad credentials" |
| TC04 | Atualização completa com novo nome e preço | positivo | AC3 | Criar reserva; PUT /booking/{id} com cookie `token`, novo `firstname`, `lastname` e `totalprice` | Status 200 e corpo com os novos valores |
| TC05 | Atualização parcial altera apenas o sobrenome | positivo | AC4 | Criar reserva; PATCH /booking/{id} com `{"lastname": "Pereira"}` e cookie `token` | Status 200; `lastname` = "Pereira"; demais campos inalterados |
| TC06 | PUT sem token é rejeitado | negativo | AC5 | Criar reserva; PUT /booking/{id} sem cookie de autenticação | Status 403 |
| TC07 | PATCH sem token é rejeitado | negativo | AC5 | Criar reserva; PATCH /booking/{id} sem cookie de autenticação | Status 403 |
| TC08 | PUT com token inválido é rejeitado | borda | AC5 | Criar reserva; PUT /booking/{id} com cookie `token=invalido` | Status 403 |
| TC09 | PUT com campo obrigatório ausente | negativo | AC6 | Criar reserva; PUT /booking/{id} com token válido e payload sem `firstname` | Status 400 |
| TC10 | PATCH com corpo vazio não altera a reserva | borda | AC4 | Criar reserva; PATCH /booking/{id} com `{}` e token válido | Status 200; todos os campos iguais aos originais |

SUPOSIÇÕES

- A URL base é `https://restful-booker.herokuapp.com`, definida na constante `BASE_URL`. Os caminhos são `/auth`, `/booking` e `/booking/{id}`.
- Autenticação: o `token` é obtido em `POST /auth` e enviado no header `Cookie: token=<valor>`. A User Story não define o mecanismo; adotei o usado pela API Restful Booker.
- Credenciais inválidas retornam o corpo `{"reason": "Bad credentials"}` sem `token`. O status HTTP não é especificado na story, então o teste TC02/TC03 não o valida.
- A senha é sensível a maiúsculas e minúsculas.
- Reservas de teste são criadas via `POST /booking` (sem autenticação) pela fixture `booking_id`, com o payload padrão: `firstname` "Ana", `lastname` "Silva", `totalprice` 100, `depositpaid` true, `bookingdates` (checkin 2026-01-10, checkout 2026-01-15) e `additionalneeds` "Breakfast". O ID é lido da chave `bookingid`.
- As reservas criadas não são removidas ao final dos testes (dados de demonstração).
- `PUT /booking/{id}` exige todos os campos obrigatórios (`firstname`, `lastname`, `totalprice`, `depositpaid`, `bookingdates`); a ausência de qualquer um resulta em 400. Isso é suposto para TC09.
- Sem token válido ou sem cookie, `PUT` e `PATCH` retornam 403.
- `PATCH` com corpo `{}` retorna 200 e mantém a reserva inalterada (TC10).
- A conexão com o host de demonstração está disponível e não há limite de requisições bloqueando a execução.
- Os testes são independentes entre si: cada teste que altera dados cria a própria reserva.

```python
import pytest
import requests

BASE_URL = "https://restful-booker.herokuapp.com"
ADMIN_USER = "admin"
ADMIN_PASSWORD = "password123"
TIMEOUT = 30


def _booking_payload(**overrides):
    payload = {
        "firstname": "Ana",
        "lastname": "Silva",
        "totalprice": 100,
        "depositpaid": True,
        "bookingdates": {"checkin": "2026-01-10", "checkout": "2026-01-15"},
        "additionalneeds": "Breakfast",
    }
    payload.update(overrides)
    return payload


def _auth_headers(token):
    return {"Cookie": f"token={token}"}


@pytest.fixture(scope="session")
def token():
    response = requests.post(
        f"{BASE_URL}/auth",
        json={"username": ADMIN_USER, "password": ADMIN_PASSWORD},
        timeout=TIMEOUT,
    )
    return response.json()["token"]


@pytest.fixture
def booking_id():
    response = requests.post(f"{BASE_URL}/booking", json=_booking_payload(), timeout=TIMEOUT)
    return response.json()["bookingid"]


def test_TC01_autenticacao_com_credenciais_validas_retorna_token():
    response = requests.post(
        f"{BASE_URL}/auth",
        json={"username": ADMIN_USER, "password": ADMIN_PASSWORD},
        timeout=TIMEOUT,
    )
    assert response.status_code == 200
    token_value = response.json().get("token")
    assert isinstance(token_value, str) and token_value.strip()


def test_TC02_autenticacao_com_senha_invalida_nao_retorna_token():
    response = requests.post(
        f"{BASE_URL}/auth",
        json={"username": ADMIN_USER, "password": "senha-errada"},
        timeout=TIMEOUT,
    )
    body = response.json()
    assert "token" not in body
    assert body.get("reason") == "Bad credentials"


def test_TC03_senha_com_caixa_diferente_nao_autentica():
    response = requests.post(
        f"{BASE_URL}/auth",
        json={"username": ADMIN_USER, "password": "PASSWORD123"},
        timeout=TIMEOUT,
    )
    body = response.json()
    assert "token" not in body
    assert body.get("reason") == "Bad credentials"


def test_TC04_atualizacao_completa_com_novo_nome_e_preco(token, booking_id):
    payload = _booking_payload(firstname="Carlos", lastname="Souza", totalprice=250)
    response = requests.put(
        f"{BASE_URL}/booking/{booking_id}",
        json=payload,
        headers=_auth_headers(token),
        timeout=TIMEOUT,
    )
    assert response.status_code == 200
    body = response.json()
    assert body["firstname"] == "Carlos"
    assert body["lastname"] == "Souza"
    assert body["totalprice"] == 250


def test_TC05_atualizacao_parcial_altera_apenas_sobrenome(token, booking_id):
    response = requests.patch(
        f"{BASE_URL}/booking/{booking_id}",
        json={"lastname": "Pereira"},
        headers=_auth_headers(token),
        timeout=TIMEOUT,
    )
    assert response.status_code == 200
    body = response.json()
    original = _booking_payload()
    assert body["lastname"] == "Pereira"
    assert body["firstname"] == original["firstname"]
    assert body["totalprice"] == original["totalprice"]
    assert body["depositpaid"] == original["depositpaid"]
    assert body["bookingdates"] == original["bookingdates"]
    assert body["additionalneeds"] == original["additionalneeds"]


def test_TC06_put_sem_token_retorna_403(booking_id):
    response = requests.put(
        f"{BASE_URL}/booking/{booking_id}",
        json=_booking_payload(firstname="Sem", lastname="Token"),
        timeout=TIMEOUT,
    )
    assert response.status_code == 403


def test_TC07_patch_sem_token_retorna_403(booking_id):
    response = requests.patch(
        f"{BASE_URL}/booking/{booking_id}",
        json={"lastname": "SemToken"},
        timeout=TIMEOUT,
    )
    assert response.status_code == 403


def test_TC08_put_com_token_invalido_retorna_403(booking_id):
    response = requests.put(
        f"{BASE_URL}/booking/{booking_id}",
        json=_booking_payload(firstname="Token", lastname="Invalido"),
        headers=_auth_headers("token-invalido"),
        timeout=TIMEOUT,
    )
    assert response.status_code == 403


def test_TC09_put_com_campo_obrigatorio_ausente_retorna_400(token, booking_id):
    payload = _booking_payload()
    del payload["firstname"]
    response = requests.put(
        f"{BASE_URL}/booking/{booking_id}",
        json=payload,
        headers=_auth_headers(token),
        timeout=TIMEOUT,
    )
    assert response.status_code == 400


def test_TC10_patch_com_corpo_vazio_nao_altera_reserva(token, booking_id):
    response = requests.patch(
        f"{BASE_URL}/booking/{booking_id}",
        json={},
        headers=_auth_headers(token),
        timeout=TIMEOUT,
    )
    assert response.status_code == 200
    body = response.json()
    original = _booking_payload()
    for field, value in original.items():
        assert body[field] == value
```

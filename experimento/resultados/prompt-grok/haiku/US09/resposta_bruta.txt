CASOS DE TESTE

| ID | Título | Tipo | Critério de Aceitação Relacionado | Passos Resumidos | Resultado Esperado |
|----|--------|------|-----------------------------------|------------------|--------------------|
| TC01 | Excluir reserva sem token | negativo | CA1 | Criar reserva; DELETE sem header de token; GET da reserva | DELETE retorna 403; GET retorna 200 |
| TC02 | Excluir reserva com token inválido | negativo | CA2 | Criar reserva; DELETE com token inválido; GET da reserva | DELETE retorna 403; reserva continua existindo (GET 200) |
| TC03 | Excluir reserva com token válido | positivo | CA3 | Obter token com admin/password123; criar reserva; DELETE com token | DELETE retorna 201 |
| TC04 | Consultar reserva excluída | positivo | CA4 | Criar e excluir reserva com token válido; GET pelo mesmo ID | GET retorna 404 |
| TC05 | Excluir reserva já excluída e isolamento de outra reserva | negativo | CA5 | Criar reservas A e B; excluir A; excluir A novamente com token; GET de B | Segunda exclusão retorna 4xx; reserva B permanece com 200 e dados íntegros |
| TC06 | Listar por nome único após exclusão | positivo | CA6 | Criar reserva com nome único; confirmar presença no filtro; excluir; filtrar por firstname/lastname | Lista antes contém o ID; lista após exclusão é vazia |
| TC07 | Excluir com token vazio | borda | CA1, CA2 | Criar reserva; DELETE com `token=` vazio; GET da reserva | DELETE retorna 403; reserva continua existindo |
| TC08 | Excluir reserva com ID inexistente | borda | CA5 | Obter token válido; DELETE de ID 999999999 | Retorna status 4xx |
| TC09 | Excluir após autenticação com credencial inválida | borda | CA1, CA2 | POST /auth com senha errada; verificar ausência de token; DELETE sem token válido; GET da reserva | Auth não retorna token; DELETE retorna 403; reserva continua existindo |

SUPOSIÇÕES

- URL base: `https://restful-booker.herokuapp.com`, definida na constante `BASE_URL`. Os endpoints são relativos a ela: `POST /auth`, `POST /booking`, `GET /booking/{id}`, `GET /booking?firstname=&lastname=`, `DELETE /booking/{id}`.
- Autenticação: `POST /auth` com JSON `{"username": "admin", "password": "password123"}` retorna `{"token": "..."}` em caso de sucesso. Com credencial inválida, a resposta não contém `token` (assume-se HTTP 200 com `reason`; o teste só verifica a ausência de `token`).
- Autorização do DELETE: o token é enviado no header `Cookie: token=<valor>`. Sem token ou com token inválido/vazio, a API retorna 403.
- Exclusão bem-sucedida retorna HTTP 201.
- Consulta a reserva inexistente ou excluída retorna HTTP 404.
- Exclusão de reserva inexistente ou já excluída retorna qualquer status 4xx (não se assume um código específico, como 405).
- Criação de reserva via `POST /booking` retorna 200 com `{"bookingid": int, "booking": {...}}`. O corpo usa os campos `firstname`, `lastname`, `totalprice`, `depositpaid`, `bookingdates` (`checkin`/`checkout`) e `additionalneeds`.
- Nomes únicos são gerados com UUID (`Tester<hex>` e `Silva<hex>`), para isolar o filtro de listagem de dados de outros testes.
- O filtro `GET /booking` com `firstname` e `lastname` retorna uma lista de objetos `{"bookingid": n}`. Quando não há correspondências, retorna lista vazia.
- Cada teste cria as próprias reservas e não depende de estado de outros testes. Não há limpeza (teardown) porque o ambiente é compartilhado e as reservas são de teste.
- A API está disponível e o ambiente é público de demonstração, sem limites de taxa relevantes. Não há uso de `time.sleep`.
- Timeout de 30 s em todas as requisições, para evitar travamentos.
- Dependências: somente `pytest` e `requests`. O arquivo é autocontido e pode ser executado com `pytest <arquivo>.py`.

```python
import uuid

import pytest
import requests

BASE_URL = "https://restful-booker.herokuapp.com"
ADMIN_USERNAME = "admin"
ADMIN_PASSWORD = "password123"
TIMEOUT = 30


def build_booking():
    return {
        "firstname": f"Tester{uuid.uuid4().hex[:8]}",
        "lastname": f"Silva{uuid.uuid4().hex[:8]}",
        "totalprice": 150,
        "depositpaid": True,
        "bookingdates": {"checkin": "2026-11-01", "checkout": "2026-11-05"},
        "additionalneeds": "Breakfast",
    }


def create_booking(booking=None):
    booking = booking or build_booking()
    response = requests.post(f"{BASE_URL}/booking", json=booking, timeout=TIMEOUT)
    assert response.status_code == 200, response.text
    body = response.json()
    return body["bookingid"], body["booking"]


def get_token():
    response = requests.post(
        f"{BASE_URL}/auth",
        json={"username": ADMIN_USERNAME, "password": ADMIN_PASSWORD},
        timeout=TIMEOUT,
    )
    assert response.status_code == 200, response.text
    return response.json()["token"]


def get_booking(booking_id):
    return requests.get(f"{BASE_URL}/booking/{booking_id}", timeout=TIMEOUT)


def delete_booking(booking_id, token=None):
    headers = {} if token is None else {"Cookie": f"token={token}"}
    return requests.delete(f"{BASE_URL}/booking/{booking_id}", headers=headers, timeout=TIMEOUT)


def test_TC01_delete_without_token_returns_403_and_booking_remains():
    booking_id, _ = create_booking()

    response = delete_booking(booking_id)

    assert response.status_code == 403
    assert get_booking(booking_id).status_code == 200


def test_TC02_delete_with_invalid_token_returns_403_and_booking_remains():
    booking_id, _ = create_booking()

    response = delete_booking(booking_id, token="invalid-token-123")

    assert response.status_code == 403
    assert get_booking(booking_id).status_code == 200


def test_TC03_delete_with_valid_token_returns_201():
    token = get_token()
    booking_id, _ = create_booking()

    response = delete_booking(booking_id, token=token)

    assert response.status_code == 201


def test_TC04_get_deleted_booking_returns_404():
    token = get_token()
    booking_id, _ = create_booking()
    assert delete_booking(booking_id, token=token).status_code == 201

    response = get_booking(booking_id)

    assert response.status_code == 404


def test_TC05_delete_already_deleted_booking_returns_4xx_and_other_booking_unaffected():
    token = get_token()
    booking_a_id, _ = create_booking()
    booking_b_id, booking_b = create_booking()
    assert delete_booking(booking_a_id, token=token).status_code == 201

    response = delete_booking(booking_a_id, token=token)

    assert 400 <= response.status_code < 500
    other = get_booking(booking_b_id)
    assert other.status_code == 200
    assert other.json()["firstname"] == booking_b["firstname"]
    assert other.json()["lastname"] == booking_b["lastname"]


def test_TC06_list_by_unique_name_is_empty_after_delete():
    token = get_token()
    booking_id, booking = create_booking()
    params = {"firstname": booking["firstname"], "lastname": booking["lastname"]}
    before = requests.get(f"{BASE_URL}/booking", params=params, timeout=TIMEOUT)
    assert {"bookingid": booking_id} in before.json()
    assert delete_booking(booking_id, token=token).status_code == 201

    response = requests.get(f"{BASE_URL}/booking", params=params, timeout=TIMEOUT)

    assert response.status_code == 200
    assert response.json() == []


def test_TC07_delete_with_empty_token_returns_403_and_booking_remains():
    booking_id, _ = create_booking()

    response = delete_booking(booking_id, token="")

    assert response.status_code == 403
    assert get_booking(booking_id).status_code == 200


def test_TC08_delete_nonexistent_booking_returns_4xx():
    token = get_token()

    response = delete_booking(999999999, token=token)

    assert 400 <= response.status_code < 500


def test_TC09_delete_after_invalid_credentials_returns_403_and_booking_remains():
    booking_id, _ = create_booking()
    response = requests.post(
        f"{BASE_URL}/auth",
        json={"username": ADMIN_USERNAME, "password": "wrong-password"},
        timeout=TIMEOUT,
    )
    assert "token" not in response.json()

    delete_response = delete_booking(booking_id)

    assert delete_response.status_code == 403
    assert get_booking(booking_id).status_code == 200
```

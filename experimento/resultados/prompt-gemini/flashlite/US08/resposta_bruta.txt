CASOS DE TESTE
| ID | Título | Tipo (Positivo/Negativo/Borda) | Critério de Aceitação Relacionado | Passos Resumidos | Resultado Esperado |
|---|---|---|---|---|---|
| CT01 | Autenticação com credenciais válidas | Positivo | Critério 1 | Enviar POST para `/auth` com usuário `admin` e senha `password123`. | Status 200 e token não vazio retornado. |
| CT02 | Autenticação com credenciais inválidas | Negativo | Critério 2 | Enviar POST para `/auth` com usuário e senha inválidos. | Status 200 ou 4xx (conforme API), sem token e mensagem "Bad credentials". |
| CT03 | Atualização completa de reserva com token válido | Positivo | Critério 3 | Criar/obter reserva, enviar PUT para `/booking/{id}` com token válido e novos dados completos (nome e preço). | Status 200 e novos valores refletidos na resposta. |
| CT04 | Atualização parcial de reserva com token válido | Positivo | Critério 4 | Criar/obter reserva, enviar PATCH para `/booking/{id}` com token válido atualizando apenas o sobrenome. | Status 200, sobrenome atualizado e demais campos intactos. |
| CT05 | Tentativa de atualização sem token de autenticação | Negativo | Critério 5 | Enviar PUT/PATCH para `/booking/{id}` sem cabeçalho de autorização. | Status 403 Forbidden (ou 401/403). |
| CT06 | Atualização completa com campos obrigatórios ausentes | Borda | Critério 6 | Enviar PUT para `/booking/{id}` com token válido omitindo campos obrigatórios no payload. | Status 400 Bad Request. |

SUPOSIÇÕES
- Endpoint base URL: `https://restful-booker.herokuapp.com`
- Endpoint de autenticação: `/auth` (método POST, payload `{"username": "...", "password": "..."}`)
- Endpoint de reservas: `/booking` (GET para listar, POST para criar, PUT/PATCH para atualizar)
- Cabeçalho de autorização para atualizações: `Cookie: token=<token>` ou `Authorization: Basic ...` dependendo da implementação, mas o padrão do Restful-Booker utiliza cookie `token=<token>` ou cabeçalho conforme documentação padrão do Restful-Booker (`Cookie: token=...`).
- Cabeçalhos padrão exigidos: `Content-Type: application/json`, `Accept: application/json`.

```python
import pytest
import requests

BASE_URL = "https://restful-booker.herokuapp.com"


@pytest.fixture(scope="session")
def auth_token():
    payload = {"username": "admin", "password": "password123"}
    headers = {"Content-Type": "application/json"}
    response = requests.post(f"{BASE_URL}/auth", json=payload, headers=headers)
    assert response.status_code == 200
    data = response.json()
    token = data.get("token")
    assert token is not None and token != ""
    return token


@pytest.fixture(scope="function")
def existing_booking_id(auth_token):
    # Create a booking to use in tests
    payload = {
        "firstname": "Jim",
        "lastname": "Brown",
        "totalprice": 111,
        "depositpaid": True,
        "bookingdates": {"checkin": "2018-01-01", "checkout": "2019-01-01"},
        "additionalneeds": "Breakfast",
    }
    headers = {
        "Content-Type": "application/json",
        "Accept": "application/json",
        "Cookie": f"token={auth_token}",
    }
    response = requests.post(f"{BASE_URL}/booking", json=payload, headers=headers)
    assert response.status_code == 200
    data = response.json()
    return data["bookingid"]


def test_CT01_autenticacao_valida():
    payload = {"username": "admin", "password": "password123"}
    headers = {"Content-Type": "application/json"}
    response = requests.post(f"{BASE_URL}/auth", json=payload, headers=headers)
    assert response.status_code == 200
    data = response.json()
    assert "token" in data
    assert data["token"] != ""


def test_CT02_autenticacao_invalida():
    payload = {"username": "invalid", "password": "wrongpassword"}
    headers = {"Content-Type": "application/json"}
    response = requests.post(f"{BASE_URL}/auth", json=payload, headers=headers)
    data = response.json()
    assert "token" not in data or data.get("token") is None
    assert data.get("reason") == "Bad credentials"


def test_CT03_atualizacao_completa_valida(auth_token, existing_booking_id):
    payload = {
        "firstname": "James",
        "lastname": "Smith",
        "totalprice": 222,
        "depositpaid": False,
        "bookingdates": {"checkin": "2020-01-01", "checkout": "2021-01-01"},
        "additionalneeds": "Lunch",
    }
    headers = {
        "Content-Type": "application/json",
        "Accept": "application/json",
        "Cookie": f"token={auth_token}",
    }
    response = requests.put(
        f"{BASE_URL}/booking/{existing_booking_id}",
        json=payload,
        headers=headers,
    )
    assert response.status_code == 200
    data = response.json()
    assert data["firstname"] == "James"
    assert data["totalprice"] == 222


def test_CT04_atualizacao_parcial_valida(auth_token, existing_booking_id):
    payload = {"lastname": "Johnson"}
    headers = {
        "Content-Type": "application/json",
        "Accept": "application/json",
        "Cookie": f"token={auth_token}",
    }
    response = requests.patch(
        f"{BASE_URL}/booking/{existing_booking_id}",
        json=payload,
        headers=headers,
    )
    assert response.status_code == 200
    data = response.json()
    assert data["lastname"] == "Johnson"
    # Ensure other fields remain intact
    assert "firstname" in data


def test_CT05_atualizacao_sem_token(existing_booking_id):
    payload = {
        "firstname": "Unauthorized",
        "lastname": "User",
        "totalprice": 100,
        "depositpaid": True,
        "bookingdates": {"checkin": "2021-01-01", "checkout": "2022-01-01"},
        "additionalneeds": "None",
    }
    headers = {"Content-Type": "application/json", "Accept": "application/json"}
    response = requests.put(
        f"{BASE_URL}/booking/{existing_booking_id}",
        json=payload,
        headers=headers,
    )
    assert response.status_code in [401, 403]


def test_CT06_atualizacao_completa_campos_ausentes(
    auth_token, existing_booking_id
):
    payload = {
        "firstname": "Incomplete"
        # Missing required fields like lastname, totalprice, bookingdates
    }
    headers = {
        "Content-Type": "application/json",
        "Accept": "application/json",
        "Cookie": f"token={auth_token}",
    }
    response = requests.put(
        f"{BASE_URL}/booking/{existing_booking_id}",
        json=payload,
        headers=headers,
    )
    assert response.status_code in [400, 500]
```

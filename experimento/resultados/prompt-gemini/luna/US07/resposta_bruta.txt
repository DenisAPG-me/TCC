## CASOS DE TESTE

| ID | Título | Tipo (Positivo/Negativo/Borda) | Critério de Aceitação Relacionado | Passos Resumidos | Resultado Esperado |
|---|---|---|---|---|---|
| CT-01 | Criar reserva com dados válidos | Positivo | 1 | Enviar todos os campos obrigatórios e adicionais com valores válidos para criação. | HTTP 200; resposta contém identificador numérico e os dados da reserva iguais aos enviados. |
| CT-02 | Consultar reserva criada | Positivo | 2 | Criar reserva e consultar pelo identificador retornado. | HTTP 200; todos os campos retornados são iguais aos enviados na criação. |
| CT-03 | Consultar identificador inexistente | Negativo | 3 | Consultar o identificador `99999999`. | HTTP 404. |
| CT-04 | Listar reservas pelo nome e sobrenome únicos | Positivo | 4 | Criar reserva com nome e sobrenome únicos e listar usando ambos como filtros. | HTTP 200; a lista inclui o identificador da reserva criada. |

## SUPOSIÇÕES

- A User Story descreve uma API REST; portanto, os testes usam `pytest` e `requests`, sem seletores de interface.
- A URL base é `https://restful-booker.herokuapp.com`.
- A criação usa `POST /booking`, com JSON contendo `firstname`, `lastname`, `totalprice`, `depositpaid`, `bookingdates` (`checkin`, `checkout`) e `additionalneeds`.
- A consulta usa `GET /booking/{bookingid}` e retorna os campos da reserva diretamente no JSON.
- A listagem filtrada usa `GET /booking?firstname={nome}&lastname={sobrenome}` e retorna uma lista de objetos contendo `bookingid`.
- Os nomes dos campos seguem o formato convencional da API Restful-Booker. Datas usam `YYYY-MM-DD`; `totalprice` é numérico e `depositpaid` é booleano.
- Os critérios não especificam rejeição de payload inválido nem outros valores de borda; não foram inferidos testes adicionais para esses comportamentos.
- Cada teste cria seus próprios dados. Os nomes para o filtro são únicos dentro da execução; os registros criados permanecem no serviço, pois a história não especifica limpeza ou exclusão.

```python
import uuid

import pytest
import requests


BASE_URL = "https://restful-booker.herokuapp.com"
REQUEST_TIMEOUT = 15


def criar_payload(nome, sobrenome):
    return {
        "firstname": nome,
        "lastname": sobrenome,
        "totalprice": 123,
        "depositpaid": True,
        "bookingdates": {
            "checkin": "2026-11-01",
            "checkout": "2026-11-05",
        },
        "additionalneeds": "Café da manhã",
    }


def criar_reserva(payload):
    response = requests.post(
        f"{BASE_URL}/booking",
        json=payload,
        timeout=REQUEST_TIMEOUT,
    )
    return response


def dados_unicos():
    sufixo = uuid.uuid4().hex[:12]
    return f"Teste{sufixo}", f"Reserva{sufixo}"


def test_CT_01_criar_reserva_com_dados_validos():
    nome, sobrenome = dados_unicos()
    payload = criar_payload(nome, sobrenome)

    response = criar_reserva(payload)

    assert response.status_code == 200, response.text
    body = response.json()
    assert isinstance(body.get("bookingid"), int)
    assert body.get("booking") == payload


def test_CT_02_consultar_reserva_criada():
    nome, sobrenome = dados_unicos()
    payload = criar_payload(nome, sobrenome)

    create_response = criar_reserva(payload)
    assert create_response.status_code == 200, create_response.text
    booking_id = create_response.json().get("bookingid")
    assert isinstance(booking_id, int)

    response = requests.get(
        f"{BASE_URL}/booking/{booking_id}",
        timeout=REQUEST_TIMEOUT,
    )

    assert response.status_code == 200, response.text
    assert response.json() == payload


def test_CT_03_consultar_identificador_inexistente():
    response = requests.get(
        f"{BASE_URL}/booking/99999999",
        timeout=REQUEST_TIMEOUT,
    )

    assert response.status_code == 404


def test_CT_04_listar_reservas_por_nome_e_sobrenome_unicos():
    nome, sobrenome = dados_unicos()
    payload = criar_payload(nome, sobrenome)

    create_response = criar_reserva(payload)
    assert create_response.status_code == 200, create_response.text
    booking_id = create_response.json().get("bookingid")
    assert isinstance(booking_id, int)

    response = requests.get(
        f"{BASE_URL}/booking",
        params={"firstname": nome, "lastname": sobrenome},
        timeout=REQUEST_TIMEOUT,
    )

    assert response.status_code == 200, response.text
    bookings = response.json()
    assert isinstance(bookings, list)
    assert any(
        isinstance(item, dict) and item.get("bookingid") == booking_id
        for item in bookings
    )
```

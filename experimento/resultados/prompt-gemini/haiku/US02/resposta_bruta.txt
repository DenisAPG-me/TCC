| ID | Título | Tipo (Positivo/Negativo/Borda) | Critério de Aceitação Relacionado | Passos Resumidos | Resultado Esperado |
|---|---|---|---|---|---|
| TC01 | Adicionar 3 unidades de Claw Hammer ao carrinho | Positivo | AC1 | Abrir Claw Hammer; definir quantidade 3; clicar em "Add to cart" | Exibe "Product added to shopping cart." e o indicador do carrinho mostra 3 |
| TC02 | Total da linha e total do carrinho com 3 unidades | Positivo | AC2 | Ler preço unitário; adicionar 3 unidades; abrir o carrinho | Total da linha = preço unitário × 3; total do carrinho = total da linha |
| TC03 | Alterar quantidade no carrinho de 3 para 1 | Positivo | AC3 | Adicionar 3 unidades; abrir carrinho; alterar quantidade para 1; clicar em "Update" | Total do carrinho = preço unitário |
| TC04 | Thor Hammer com 3 unidades é recusado | Negativo | AC4 | Abrir Thor Hammer; definir quantidade 3; clicar em "Add to cart" | Exibe "You can only have one Thor Hammer in the cart." |
| TC05 | Quantidade padrão é 1 ao adicionar sem alterar | Borda | AC1 (derivado) | Abrir Claw Hammer; verificar quantidade padrão; clicar em "Add to cart" | Campo de quantidade inicia com 1; confirmação exibida; indicador do carrinho mostra 1 |
| TC06 | Quantidade 0 não adiciona produto ao carrinho | Negativo | AC1 (derivado) | Abrir Claw Hammer; definir quantidade 0; clicar em "Add to cart" | Confirmação "Product added to shopping cart." não é exibida |
| TC07 | Thor Hammer com 1 unidade é aceito (limite) | Borda | AC4 (limite) | Abrir Thor Hammer; definir quantidade 1; clicar em "Add to cart" | Exibe confirmação; indicador do carrinho mostra 1 |

## SUPOSIÇÕES

- **URL base:** `https://practicesoftwaretesting.com`, definida na constante `BASE_URL`.
- **Carrinho inicial vazio:** o plugin pytest-playwright cria um contexto de navegador novo para cada teste.
- **Home:** os produtos são links cujo nome acessível contém o nome do produto (ex.: `get_by_role("link", name="Claw Hammer")`).
- **Página do produto:**
  - Título do produto como `heading` com o nome do produto.
  - Preço unitário no elemento `[data-test="unit-price"]`.
  - Campo de quantidade com label "Quantity", valor padrão `1`, mínimo `1`.
  - Botão "Add to cart".
  - Mensagens de confirmação e de erro exibidas como texto visível.
- **Cabeçalho:** link de navegação com nome contendo "Cart" para abrir o carrinho.
- **Indicador do carrinho:** `[data-test="cart-quantity"]`, com a soma das unidades.
- **Página do carrinho:**
  - Preço da linha em `[data-test="line-price"]`.
  - Total do carrinho em `[data-test="cart-total"]`.
  - Campo de quantidade da linha com role `spinbutton`.
  - Botão "Update" para aplicar a alteração de quantidade.
- **Formato monetário:** valores como `$12.34` (símbolo opcional, duas casas decimais, ponto como separador).
- **Thor Hammer:** limite de 1 unidade por carrinho. A mensagem de erro é exatamente "You can only have one Thor Hammer in the cart.".
- **Quantidade 0:** rejeitada pela aplicação, de modo que a confirmação não aparece (TC06).
- **Seletores `data-test`:** usados com `locator` explícito, pois o atributo padrão do `get_by_test_id` é `data-testid`.
- **Limite máximo de quantidade:** desconhecido, não testado.

```python
import re

import pytest
from playwright.sync_api import Page, expect

BASE_URL = "https://practicesoftwaretesting.com"

CONFIRMATION_MSG = "Product added to shopping cart."
THOR_HAMMER_MSG = "You can only have one Thor Hammer in the cart."

CART_BADGE = '[data-test="cart-quantity"]'
UNIT_PRICE = '[data-test="unit-price"]'
LINE_PRICE = '[data-test="line-price"]'
CART_TOTAL = '[data-test="cart-total"]'


def money(value: float) -> re.Pattern:
    text = f"{value:.2f}"
    return re.compile(rf"^\D*{re.escape(text)}\s*$")


def parse_money(text: str) -> float:
    return float(re.sub(r"[^\d.]", "", text))


def open_product(page: Page, name: str) -> None:
    page.goto(BASE_URL)
    page.get_by_role("link", name=name).click()
    expect(page.get_by_role("heading", name=name)).to_be_visible()


def read_unit_price(page: Page) -> float:
    price = page.locator(UNIT_PRICE)
    expect(price).not_to_be_empty()
    return parse_money(price.inner_text())


def add_to_cart(page: Page, quantity: str | None = None) -> None:
    if quantity is not None:
        page.get_by_label("Quantity").fill(quantity)
    page.get_by_role("button", name="Add to cart").click()


def open_cart(page: Page) -> None:
    page.get_by_role("link", name=re.compile("Cart")).click()
    expect(page.get_by_role("spinbutton")).to_be_visible()


def test_TC01_adicionar_3_claw_hammer_exibe_confirmacao_e_badge(page: Page):
    open_product(page, "Claw Hammer")
    add_to_cart(page, "3")
    expect(page.get_by_text(CONFIRMATION_MSG)).to_be_visible()
    expect(page.locator(CART_BADGE)).to_have_text("3")


def test_TC02_linha_e_total_do_carrinho_igual_preco_vezes_3(page: Page):
    open_product(page, "Claw Hammer")
    unit = read_unit_price(page)
    add_to_cart(page, "3")
    expect(page.get_by_text(CONFIRMATION_MSG)).to_be_visible()
    open_cart(page)
    expected = round(unit * 3, 2)
    expect(page.locator(LINE_PRICE)).to_have_text(money(expected))
    expect(page.locator(CART_TOTAL)).to_have_text(money(expected))


def test_TC03_alterar_quantidade_para_1_total_igual_preco_unitario(page: Page):
    open_product(page, "Claw Hammer")
    unit = read_unit_price(page)
    add_to_cart(page, "3")
    expect(page.get_by_text(CONFIRMATION_MSG)).to_be_visible()
    open_cart(page)
    page.get_by_role("spinbutton").fill("1")
    page.get_by_role("button", name="Update").click()
    expect(page.locator(CART_TOTAL)).to_have_text(money(unit))


def test_TC04_thor_hammer_3_unidades_exibe_mensagem_de_limite(page: Page):
    open_product(page, "Thor Hammer")
    add_to_cart(page, "3")
    expect(page.get_by_text(THOR_HAMMER_MSG)).to_be_visible()


def test_TC05_quantidade_padrao_1_ao_adicionar_sem_alterar(page: Page):
    open_product(page, "Claw Hammer")
    expect(page.get_by_label("Quantity")).to_have_value("1")
    add_to_cart(page)
    expect(page.get_by_text(CONFIRMATION_MSG)).to_be_visible()
    expect(page.locator(CART_BADGE)).to_have_text("1")


def test_TC06_quantidade_zero_nao_adiciona_ao_carrinho(page: Page):
    open_product(page, "Claw Hammer")
    add_to_cart(page, "0")
    expect(page.get_by_text(CONFIRMATION_MSG)).to_have_count(0)


def test_TC07_thor_hammer_1_unidade_e_aceito(page: Page):
    open_product(page, "Thor Hammer")
    add_to_cart(page, "1")
    expect(page.get_by_text(CONFIRMATION_MSG)).to_be_visible()
    expect(page.locator(CART_BADGE)).to_have_text("1")


if __name__ == "__main__":
    raise SystemExit(pytest.main([__file__, "-v"]))
```

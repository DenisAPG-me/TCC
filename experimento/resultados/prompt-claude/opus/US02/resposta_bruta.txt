| ID | Título | Tipo | Critério de Aceitação | Passos | Resultado Esperado |
|----|--------|------|-----------------------|--------|--------------------|
| CT01 | Adicionar 3 unidades de Claw Hammer ao carrinho | Positivo | CA1 | Acessar a URL base; pesquisar "Claw Hammer"; abrir a página do produto; definir quantidade 3; clicar em "Add to cart" | A mensagem "Product added to shopping cart." é exibida e o indicador do carrinho mostra 3 |
| CT02 | Validar total da linha e total do carrinho com 3 unidades | Positivo | CA2 | Abrir a página do "Claw Hammer"; registrar o preço unitário; adicionar 3 unidades ao carrinho; abrir o carrinho | O carrinho lista o "Claw Hammer" com quantidade 3, o total da linha é igual a preço unitário x 3 e o total do carrinho é igual ao total da linha |
| CT03 | Alterar a quantidade no carrinho de 3 para 1 | Positivo | CA3 | Abrir a página do "Claw Hammer"; registrar o preço unitário; adicionar 3 unidades ao carrinho; abrir o carrinho; alterar a quantidade para 1 e confirmar | O total da linha e o total do carrinho passam a ser iguais ao preço unitário |
| CT04 | Bloquear a adição de 3 unidades de Thor Hammer | Negativo | CA4 | Acessar a URL base; pesquisar "Thor Hammer"; abrir a página do produto; definir quantidade 3; clicar em "Add to cart" | A mensagem "You can only have one Thor Hammer in the cart." é exibida e a confirmação "Product added to shopping cart." não é exibida |
| CT05 | Adicionar a quantidade mínima (1) de Claw Hammer | Borda | CA1, CA2 | Abrir a página do "Claw Hammer"; registrar o preço unitário; manter a quantidade 1; clicar em "Add to cart"; abrir o carrinho | A confirmação "Product added to shopping cart." é exibida, o indicador do carrinho mostra 1 e o total do carrinho é igual ao preço unitário |
| CT06 | Adicionar exatamente 1 unidade de Thor Hammer (limite permitido) | Borda | CA4 | Abrir a página do "Thor Hammer"; definir quantidade 1; clicar em "Add to cart" | A confirmação "Product added to shopping cart." é exibida, o indicador do carrinho mostra 1 e a mensagem de limite não é exibida |

## SUPOSIÇÕES

- Tecnologia: interface web, portanto Python + pytest + plugin oficial pytest-playwright (API síncrona), usando as fixtures `page` e `playwright` fornecidas pelo plugin, conforme os requisitos técnicos obrigatórios (que prevalecem sobre a instrução anterior de criar o navegador com `sync_playwright`). Execução: `pytest arquivo.py` (o plugin roda o Chromium em headless por padrão).
- Dependências: `pytest`, `pytest-playwright` e o Chromium instalado via `playwright install chromium`.
- A aplicação usa atributos `data-test` nos elementos. Por isso, `get_by_test_id` é configurado com `playwright.selectors.set_test_id_attribute("data-test")` em uma fixture de sessão autouse.
- Seletores deduzidos: busca `search-query` e `search-submit`; nome do produto `product-name` (no card e na página de detalhe); preço unitário `unit-price`; campo de quantidade `quantity`; botão `add-to-cart`; indicador do carrinho `cart-quantity`; link do carrinho `nav-cart`; no carrinho, `product-title`, `product-quantity`, `line-price` e `cart-total`.
- A página do carrinho fica em uma URL que contém `/checkout`.
- O preço unitário na página do produto contém um número decimal com duas casas (ex.: `14.15`). Os totais no carrinho são exibidos com duas casas e podem ter o prefixo `$`.
- A alteração de quantidade no carrinho é aplicada no evento `change` do campo, disparado ao sair dele (tecla Tab), e os totais são recalculados automaticamente.
- As mensagens são exibidas como toast com os textos exatos dos critérios: "Product added to shopping cart." e "You can only have one Thor Hammer in the cart.".
- Os produtos "Claw Hammer" e "Thor Hammer" existem, estão disponíveis em estoque e são encontrados pela busca. O card é localizado pelo nome exato, para não confundir com produtos de nome semelhante.
- O carrinho é mantido no armazenamento do navegador. Como o pytest-playwright cria um contexto novo por teste, cada teste começa com o carrinho vazio, o que garante a independência entre os testes.
- A base URL vem da constante `BASE_URL` no topo do arquivo.

## SCRIPT

```python
import re
from decimal import Decimal

import pytest
from playwright.sync_api import Page, expect

BASE_URL = "https://practicesoftwaretesting.com"
PRODUCT_NAME = "Claw Hammer"
LIMITED_PRODUCT_NAME = "Thor Hammer"
QUANTITY = 3
UPDATED_QUANTITY = 1
MIN_QUANTITY = 1
MSG_PRODUCT_ADDED = "Product added to shopping cart."
MSG_THOR_LIMIT = "You can only have one Thor Hammer in the cart."
TIMEOUT = 15000


@pytest.fixture(scope="session", autouse=True)
def configure_test_id_attribute(playwright):
    playwright.selectors.set_test_id_attribute("data-test")


def open_product(page: Page, name: str) -> None:
    page.goto(f"{BASE_URL}/")
    page.get_by_test_id("search-query").fill(name)
    page.get_by_test_id("search-submit").click()
    card = page.get_by_test_id("product-name").filter(
        has_text=re.compile(rf"^\s*{re.escape(name)}\s*$")
    ).first
    expect(card).to_be_visible(timeout=TIMEOUT)
    card.click()
    expect(page.get_by_test_id("product-name")).to_have_text(name, timeout=TIMEOUT)


def get_unit_price(page: Page) -> Decimal:
    price = page.get_by_test_id("unit-price")
    expect(price).to_have_text(re.compile(r"\d+\.\d{2}"), timeout=TIMEOUT)
    return Decimal(re.search(r"\d+\.\d{2}", price.inner_text()).group())


def add_to_cart(page: Page, quantity: int) -> None:
    page.get_by_test_id("quantity").fill(str(quantity))
    page.get_by_test_id("add-to-cart").click()


def open_cart(page: Page) -> None:
    page.get_by_test_id("nav-cart").click()
    expect(page).to_have_url(re.compile(r"/checkout"), timeout=TIMEOUT)


def money(value: Decimal) -> re.Pattern:
    return re.compile(rf"^\s*\$?\s*{re.escape(f'{value:.2f}')}\s*$")


def test_ct01_adicionar_tres_unidades_ao_carrinho(page: Page):
    open_product(page, PRODUCT_NAME)
    add_to_cart(page, QUANTITY)

    expect(page.get_by_text(MSG_PRODUCT_ADDED)).to_be_visible(timeout=TIMEOUT)
    expect(page.get_by_test_id("cart-quantity")).to_have_text(str(QUANTITY), timeout=TIMEOUT)


def test_ct02_validar_total_da_linha_e_do_carrinho(page: Page):
    open_product(page, PRODUCT_NAME)
    unit_price = get_unit_price(page)
    add_to_cart(page, QUANTITY)
    expect(page.get_by_test_id("cart-quantity")).to_have_text(str(QUANTITY), timeout=TIMEOUT)

    open_cart(page)

    expected_line_total = unit_price * QUANTITY
    expect(page.get_by_test_id("product-title")).to_contain_text(PRODUCT_NAME, timeout=TIMEOUT)
    expect(page.get_by_test_id("product-quantity")).to_have_value(str(QUANTITY), timeout=TIMEOUT)
    expect(page.get_by_test_id("line-price")).to_have_text(money(expected_line_total), timeout=TIMEOUT)
    expect(page.get_by_test_id("cart-total")).to_have_text(money(expected_line_total), timeout=TIMEOUT)


def test_ct03_alterar_quantidade_no_carrinho_para_um(page: Page):
    open_product(page, PRODUCT_NAME)
    unit_price = get_unit_price(page)
    add_to_cart(page, QUANTITY)
    expect(page.get_by_test_id("cart-quantity")).to_have_text(str(QUANTITY), timeout=TIMEOUT)

    open_cart(page)
    expect(page.get_by_test_id("cart-total")).to_have_text(money(unit_price * QUANTITY), timeout=TIMEOUT)

    quantity_input = page.get_by_test_id("product-quantity")
    quantity_input.fill(str(UPDATED_QUANTITY))
    quantity_input.press("Tab")

    expect(page.get_by_test_id("line-price")).to_have_text(money(unit_price), timeout=TIMEOUT)
    expect(page.get_by_test_id("cart-total")).to_have_text(money(unit_price), timeout=TIMEOUT)


def test_ct04_bloquear_tres_unidades_de_thor_hammer(page: Page):
    open_product(page, LIMITED_PRODUCT_NAME)
    add_to_cart(page, QUANTITY)

    expect(page.get_by_text(MSG_THOR_LIMIT)).to_be_visible(timeout=TIMEOUT)
    expect(page.get_by_text(MSG_PRODUCT_ADDED)).not_to_be_visible()


def test_ct05_adicionar_quantidade_minima(page: Page):
    open_product(page, PRODUCT_NAME)
    unit_price = get_unit_price(page)
    add_to_cart(page, MIN_QUANTITY)

    expect(page.get_by_text(MSG_PRODUCT_ADDED)).to_be_visible(timeout=TIMEOUT)
    expect(page.get_by_test_id("cart-quantity")).to_have_text(str(MIN_QUANTITY), timeout=TIMEOUT)

    open_cart(page)
    expect(page.get_by_test_id("cart-total")).to_have_text(money(unit_price), timeout=TIMEOUT)


def test_ct06_adicionar_uma_unidade_de_thor_hammer(page: Page):
    open_product(page, LIMITED_PRODUCT_NAME)
    add_to_cart(page, MIN_QUANTITY)

    expect(page.get_by_text(MSG_PRODUCT_ADDED)).to_be_visible(timeout=TIMEOUT)
    expect(page.get_by_test_id("cart-quantity")).to_have_text(str(MIN_QUANTITY), timeout=TIMEOUT)
    expect(page.get_by_text(MSG_THOR_LIMIT)).not_to_be_visible()
```

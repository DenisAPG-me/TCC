|----|--------|------|-----------------------|--------|--------------------|

| CT02 | Enviar contato válido | Positivo | CA2 | Abrir a página inicial; preencher todos os campos com dados válidos; enviar | Confirmação exibe exatamente Thanks for getting in touch seguido do nome informado e exclamação |
| CT03 | Incrementar contador após envio | Positivo | CA1, CA2, CA3 | Autenticar; registrar contador; sair; enviar contato válido; autenticar novamente; comparar contador | Visitante recebe confirmação e contador aumenta exatamente uma unidade |
| CT04 | Localizar mensagem enviada | Positivo | CA2, CA4 | Enviar contato com assunto exclusivo; autenticar como administrador; abrir Messages; localizar mensagem | Uma linha apresenta exatamente o nome e o assunto enviados |
| CT05 | Bloquear acesso direto após logout | Negativo | CA5 | Autenticar; abrir Messages; sair; acessar diretamente a URL da caixa de mensagens | Formulário de login é apresentado e lista de mensagens não fica visível |

## SUPOSIÇÕES

- A análise usa somente a User Story. O sistema não foi acessado; seletores, rotas e comportamentos deduzidos precisam ser conferidos antes do uso real. O script não foi executado.
- Os critérios fornecidos correspondem, na ordem, a CA1 até CA5.
- O foco é interface web. São usados Python, pytest, Playwright síncrono e o plugin oficial pytest-playwright. Os requisitos técnicos finais prevalecem sobre a proibição anterior de plugins e a exigência anterior de fixtures próprias.
- O ambiente deve ter pytest, playwright e pytest-playwright instalados, além do Chromium instalado pelo Playwright. O comando `pytest arquivo.py` usa Chromium headless por padrão; o plugin cria e encerra os recursos e fornece uma página isolada para cada teste.
- A página inicial está em `/`, o painel em `/admin` e a caixa de mensagens em `/admin/messages`. O acesso é feito pela interface; nenhum endpoint de API ou payload HTTP é presumido.
- O login possui campos com rótulos acessíveis `Username` e `Password` e botão `Login`. As credenciais são `admin` e `password`.
- O painel possui um link cujo nome acessível segue `Messages N` ou `Messages (N)`, sendo N um inteiro não negativo. O contador está incluído no texto do link e atualiza após recarregar o painel.
- O logout é um botão com nome acessível `Logout`. Após sair, o formulário de login aparece. Acesso direto sem sessão à caixa de mensagens também apresenta esse formulário.
- O formulário de contato contém campos com rótulos acessíveis exatos `Name`, `Email`, `Phone`, `Subject` e `Message`, únicos na página, e botão `Submit`.
- A confirmação é um elemento de texto único, exatamente `Thanks for getting in touch <nome>!`.
- Nome, assunto, e-mail, telefone e corpo usados no script são dados sintéticos considerados válidos. Um identificador aleatório no assunto distingue mensagens criadas por execuções diferentes. CT07 reutiliza intencionalmente os mesmos dados nos dois envios.
- A caixa usa uma tabela HTML, com nome e assunto em células separadas. Mensagens recém-enviadas aparecem sem exigir pesquisa ou paginação.
- O contador representa mensagens recebidas e não diminui apenas ao abrir a caixa. Cada envio aceito acrescenta uma unidade, inclusive quando os dados são iguais.
- CT06 acrescenta uma regra deduzida: o campo de e-mail usa validação HTML nativa, rejeita `email-invalido` e impede a criação da mensagem. Essa regra não está explicitamente definida nos critérios.
- CT07 cobre a borda de repetição de dados; não presume limites de tamanho ausentes na história.
- Para comparar incrementos exatos, a execução ocorre sequencialmente em ambiente sem envios, exclusões ou outras alterações concorrentes. Um ambiente público compartilhado pode violar essa condição.
- Cada teste prepara seu próprio estado e não depende de mensagens de outros testes. As mensagens criadas permanecem no sistema, pois a história não define exclusão nem limpeza.
- Elementos e atualizações devem ficar disponíveis em até 15 segundos; navegações têm limite de 30 segundos. As verificações usam a espera automática de `expect`, sem pausas fixas.

## SCRIPT

```python
import re
from uuid import uuid4

from playwright.sync_api import Page, expect


BASE_URL = "https://automationintesting.online"
ADMIN_URL = f"{BASE_URL}/admin"
MESSAGES_URL = f"{BASE_URL}/admin/messages"

ADMIN_USERNAME = "admin"
ADMIN_PASSWORD = "password"

CONTACT_NAME = "Visitante Teste"
CONTACT_EMAIL = "visitante.teste@example.com"
CONTACT_PHONE = "11987654321"
CONTACT_SUBJECT_PREFIX = "Consulta de hospedagem"
CONTACT_BODY = (
    "Ola, gostaria de consultar a disponibilidade de hospedagem "
    "para duas pessoas no proximo mes."
)
INVALID_EMAIL = "email-invalido"

UI_TIMEOUT_MS = 15_000
NAVIGATION_TIMEOUT_MS = 30_000

MESSAGES_NAME = re.compile(r"^Messages\b", re.IGNORECASE)
COUNTER_PATTERN = re.compile(
    r"^\s*Messages\s+(?:[0-9]+|\(\s*[0-9]+\s*\))\s*$",
    re.IGNORECASE,
)


def configure(page: Page) -> None:
    page.set_default_timeout(UI_TIMEOUT_MS)
    page.set_default_navigation_timeout(NAVIGATION_TIMEOUT_MS)


def navigate(page: Page, url: str) -> None:
    page.goto(url, wait_until="domcontentloaded")


def new_contact() -> dict[str, str]:
    return {
        "name": CONTACT_NAME,
        "email": CONTACT_EMAIL,
        "phone": CONTACT_PHONE,
        "subject": f"{CONTACT_SUBJECT_PREFIX} {uuid4().hex[:12]}",
        "message": CONTACT_BODY,
    }


def messages_link(page: Page):
    return page.get_by_role("link", name=MESSAGES_NAME)


def expect_login(page: Page) -> None:
    expect(
        page.get_by_label("Username", exact=True)
    ).to_be_visible(timeout=UI_TIMEOUT_MS)
    expect(page.get_by_label("Password", exact=True)).to_be_visible(
        timeout=UI_TIMEOUT_MS
    )
    expect(
        page.get_by_role("button", name="Login", exact=True)
    ).to_be_visible(timeout=UI_TIMEOUT_MS)


def login(page: Page) -> None:
    navigate(page, ADMIN_URL)
    expect_login(page)
    page.get_by_label("Username", exact=True).fill(ADMIN_USERNAME)
    page.get_by_label("Password", exact=True).fill(ADMIN_PASSWORD)
    page.get_by_role("button", name="Login", exact=True).click()
    expect(messages_link(page)).to_be_visible(timeout=UI_TIMEOUT_MS)


def logout(page: Page) -> None:
    page.get_by_role("button", name="Logout", exact=True).click()
    expect_login(page)


def read_counter(page: Page) -> int:
    link = messages_link(page)
    expect(link).to_have_text(COUNTER_PATTERN, timeout=UI_TIMEOUT_MS)
    text = link.inner_text()
    match = re.fullmatch(COUNTER_PATTERN, text)
    if match is None:
        raise AssertionError(f"Formato inesperado do contador: {text!r}")
    return int(re.search(r"[0-9]+", match.group(0)).group(0))


def expect_counter(page: Page, expected: int) -> None:
    pattern = re.compile(
        rf"^\s*Messages\s+(?:{expected}|\(\s*{expected}\s*\))\s*$",
        re.IGNORECASE,
    )
    expect(messages_link(page)).to_have_text(
        pattern, timeout=UI_TIMEOUT_MS
    )


def confirmation(page: Page, contact: dict[str, str]):
    return page.get_by_text(
        f"Thanks for getting in touch {contact['name']}!",
        exact=True,
    )


def fill_contact(page: Page, contact: dict[str, str]) -> None:
    navigate(page, f"{BASE_URL}/")
    for label, key in (
        ("Name", "name"),
        ("Email", "email"),
        ("Phone", "phone"),
        ("Subject", "subject"),
        ("Message", "message"),
    ):
        page.get_by_label(label, exact=True).fill(contact[key])


def send_contact(page: Page, contact: dict[str, str]) -> None:
    fill_contact(page, contact)
    page.get_by_role("button", name="Submit", exact=True).click()
    expect(confirmation(page, contact)).to_be_visible(
        timeout=UI_TIMEOUT_MS
    )


def open_messages(page: Page) -> None:
    messages_link(page).click()
    expect(page.get_by_role("table")).to_be_visible(
        timeout=UI_TIMEOUT_MS
    )


def matching_rows(page: Page, contact: dict[str, str]):
    return (
        page.get_by_role("table")
        .get_by_role("row")
        .filter(
            has=page.get_by_role(
                "cell", name=contact["name"], exact=True
            )
        )
        .filter(
            has=page.get_by_role(
                "cell", name=contact["subject"], exact=True
            )
        )
    )


def expect_messages(
    page: Page, contact: dict[str, str], quantity: int
) -> None:
    rows = matching_rows(page, contact)
    expect(rows).to_have_count(quantity, timeout=UI_TIMEOUT_MS)
    for index in range(quantity):
        row = rows.nth(index)
        expect(
            row.get_by_role("cell", name=contact["name"], exact=True)
        ).to_be_visible(timeout=UI_TIMEOUT_MS)
        expect(
            row.get_by_role("cell", name=contact["subject"], exact=True)
        ).to_be_visible(timeout=UI_TIMEOUT_MS)


def test_ct01_consultar_contador_inicial(page: Page) -> None:
    configure(page)
    login(page)
    initial = read_counter(page)

    page.reload(wait_until="domcontentloaded")

    expect_counter(page, initial)


def test_ct02_enviar_contato_valido(page: Page) -> None:
    configure(page)
    contact = new_contact()

    send_contact(page, contact)

    expect(confirmation(page, contact)).to_have_text(
        f"Thanks for getting in touch {contact['name']}!",
        timeout=UI_TIMEOUT_MS,
    )


def test_ct03_incrementar_contador_apos_envio(page: Page) -> None:
    configure(page)
    contact = new_contact()
    login(page)
    initial = read_counter(page)
    logout(page)

    send_contact(page, contact)
    login(page)

    expect_counter(page, initial + 1)


def test_ct04_localizar_mensagem_enviada(page: Page) -> None:
    configure(page)
    contact = new_contact()

    send_contact(page, contact)
    login(page)
    open_messages(page)

    expect_messages(page, contact, quantity=1)


def test_ct05_bloquear_acesso_direto_apos_logout(page: Page) -> None:
    configure(page)
    login(page)
    open_messages(page)
    logout(page)

    navigate(page, MESSAGES_URL)

    expect_login(page)
    expect(page.get_by_role("table")).to_have_count(
        0, timeout=UI_TIMEOUT_MS
    )
    expect(messages_link(page)).to_have_count(
        0, timeout=UI_TIMEOUT_MS
    )


def test_ct06_rejeitar_email_invalido(page: Page) -> None:
    configure(page)
    contact = new_contact()
    contact["email"] = INVALID_EMAIL
    login(page)
    initial = read_counter(page)
    logout(page)

    fill_contact(page, contact)
    page.get_by_role("button", name="Submit", exact=True).click()

    email = page.get_by_label("Email", exact=True)
    expect(email).to_be_visible(timeout=UI_TIMEOUT_MS)
    expect(email).to_have_value(INVALID_EMAIL, timeout=UI_TIMEOUT_MS)
    expect(email.and_(page.locator(":invalid"))).to_have_count(
        1, timeout=UI_TIMEOUT_MS
    )
    expect(confirmation(page, contact)).to_have_count(
        0, timeout=UI_TIMEOUT_MS
    )

    login(page)
    expect_counter(page, initial)


def test_ct07_processar_dois_envios_iguais(page: Page) -> None:
    configure(page)
    contact = new_contact()
    login(page)
    initial = read_counter(page)
    logout(page)

    send_contact(page, contact)
    login(page)
    expect_counter(page, initial + 1)
    logout(page)

    send_contact(page, contact)
    login(page)
    expect_counter(page, initial + 2)
    open_messages(page)

    expect_messages(page, contact, quantity=2)
```

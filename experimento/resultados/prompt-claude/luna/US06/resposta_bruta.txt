## CASOS DE TESTE

| ID | Título | Tipo | Critério de Aceitação | Passos | Resultado Esperado |
|----|--------|------|-----------------------|--------|--------------------|
| CT01 | Enviar mensagem válida como visitante | Positivo | CA2 | Abrir a página inicial; preencher nome, assunto, e-mail e mensagem válidos; enviar o formulário | A página exibe “Thanks for getting in touch <nome>!” com o nome informado |
| CT02 | Conferir incremento do contador e mensagem recebida | Positivo | CA1, CA3, CA4 | Fazer login; anotar o contador de Messages; enviar mensagem válida como visitante; abrir o painel; conferir o contador e abrir Messages | O contador aumenta exatamente uma unidade e a lista contém o nome e o assunto enviados |
| CT03 | Bloquear envio sem nome | Negativo | CA2 | Abrir a página inicial; preencher os demais campos obrigatórios e deixar o nome vazio; enviar o formulário | A mensagem não é enviada e a confirmação de sucesso não aparece |
| CT04 | Bloquear envio sem assunto | Negativo | CA2 | Abrir a página inicial; preencher os demais campos obrigatórios e deixar o assunto vazio; enviar o formulário | A mensagem não é enviada e a confirmação de sucesso não aparece |
| CT05 | Solicitar login ao abrir Messages após logout | Positivo | CA5 | Fazer login; sair do painel; abrir diretamente a URL de Messages | O administrador é redirecionado à tela de login ou recebe solicitação para se autenticar |

## SUPOSIÇÕES

- A história descreve principalmente fluxos de interface web, então a automação usa Python, pytest e Playwright.
- Foi seguida a exigência técnica final de usar a fixture `page` do plugin oficial pytest-playwright e `expect` de `playwright.sync_api`. Isso conflita com a exigência anterior de não usar plugins e criar as fixtures localmente; prevaleceu a exigência técnica marcada como obrigatória em caso de conflito. É necessário instalar `pytest-playwright` além de pytest e Playwright.
- A URL base é `https://automationintesting.online/`; o painel está em `/admin`, conforme informado.
- O login usa os campos rotulados `Username` e `Password`, credenciais `admin` e `password`, e botão `Login`.
- A tela de administração exibe um link ou botão `Messages`, cujo texto inclui o contador, e a caixa de mensagens fica em `/admin/messages`.
- O logout é feito por um controle com nome acessível `Logout`; após logout, o acesso direto a `/admin/messages` redireciona para `/admin`.
- O formulário público contém campos acessíveis rotulados `Name`, `Email`, `Phone` e `Subject`, além de um campo `Message`; o envio ocorre pelo botão `Submit`.
- Nome, e-mail, telefone, assunto e conteúdo da mensagem são obrigatórios, e e-mail válido é necessário para o envio. Os dados de teste são únicos por execução para facilitar identificar a mensagem.
- O sucesso do envio é mostrado no texto `Thanks for getting in touch <nome>!`.
- CT02 compara o contador anterior e posterior ao envio da própria mensagem. Como a história não define como armazenar estado entre testes, o caso realiza os passos no mesmo teste.
- Nos cenários sem nome ou assunto, espera-se validação do formulário ou ausência de confirmação de sucesso; não se presume texto específico para a validação.
- Seletores e caminhos não especificados foram deduzidos e podem precisar de ajuste conforme a implementação real.

## SCRIPT

```python
import uuid

import pytest
from playwright.sync_api import expect


BASE_URL = "https://automationintesting.online/"
ADMIN_USERNAME = "admin"
ADMIN_PASSWORD = "password"

TEST_ID = uuid.uuid4().hex[:8]
VISITOR_NAME = f"Visitante {TEST_ID}"
VISITOR_EMAIL = f"visitante-{TEST_ID}@example.com"
VISITOR_PHONE = "11999999999"
VISITOR_SUBJECT = f"Assunto {TEST_ID}"
VISITOR_MESSAGE = f"Mensagem de teste {TEST_ID}"

ADMIN_URL = f"{BASE_URL}admin"
MESSAGES_URL = f"{ADMIN_URL}/messages"


def login(page):
    page.goto(ADMIN_URL)
    page.get_by_label("Username").fill(ADMIN_USERNAME)
    page.get_by_label("Password").fill(ADMIN_PASSWORD)
    page.get_by_role("button", name="Login").click()


def fill_contact_form(page, name=VISITOR_NAME, subject=VISITOR_SUBJECT):
    page.goto(BASE_URL)
    page.get_by_label("Name").fill(name)
    page.get_by_label("Email").fill(VISITOR_EMAIL)
    page.get_by_label("Phone").fill(VISITOR_PHONE)
    page.get_by_label("Subject").fill(subject)
    page.get_by_label("Message").fill(VISITOR_MESSAGE)


def submit_contact_form(page):
    page.get_by_role("button", name="Submit").click()


def read_messages_count(page):
    messages_link = page.get_by_role("link", name="Messages")
    expect(messages_link).to_be_visible()
    label = messages_link.inner_text()
    digits = "".join(character for character in label if character.isdigit())
    assert digits, f"Não foi possível encontrar o contador no texto: {label!r}"
    return int(digits)


def test_ct01_enviar_mensagem_valida_como_visitante(page):
    fill_contact_form(page)
    submit_contact_form(page)

    expect(
        page.get_by_text(f"Thanks for getting in touch {VISITOR_NAME}!", exact=True)
    ).to_be_visible()


def test_ct02_conferir_incremento_e_mensagem_recebida(page):
    login(page)
    count_before = read_messages_count(page)

    fill_contact_form(page)
    submit_contact_form(page)
    expect(
        page.get_by_text(f"Thanks for getting in touch {VISITOR_NAME}!", exact=True)
    ).to_be_visible()

    login(page)
    count_after = read_messages_count(page)
    assert count_after == count_before + 1

    page.get_by_role("link", name="Messages").click()
    expect(page.get_by_text(VISITOR_NAME, exact=True)).to_be_visible()
    expect(page.get_by_text(VISITOR_SUBJECT, exact=True)).to_be_visible()


def test_ct03_bloquear_envio_sem_nome(page):
    fill_contact_form(page, name="")
    submit_contact_form(page)

    expect(
        page.get_by_text(f"Thanks for getting in touch {VISITOR_NAME}!", exact=True)
    ).to_have_count(0)


def test_ct04_bloquear_envio_sem_assunto(page):
    fill_contact_form(page, subject="")
    submit_contact_form(page)

    expect(
        page.get_by_text(f"Thanks for getting in touch {VISITOR_NAME}!", exact=True)
    ).to_have_count(0)


def test_ct05_solicitar_login_apos_logout(page):
    login(page)
    page.get_by_role("link", name="Logout").click()
    page.goto(MESSAGES_URL)

    expect(page).to_have_url(f"{ADMIN_URL}/")
    expect(page.get_by_label("Username")).to_be_visible()
    expect(page.get_by_label("Password")).to_be_visible()
```

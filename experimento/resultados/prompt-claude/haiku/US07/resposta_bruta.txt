|----|--------|------|-----------------------|--------|--------------------|

| CT02 | Consultar reserva criada pelo identificador | Positivo | CA2 | Criar reserva via POST /booking; consultar GET /booking/{id} com o bookingid retornado; comparar corpo | Status 200; todos os campos iguais aos enviados |

## SUPOSIÇÕES

- Tecnologia: a User Story é de API REST, então usei Python + pytest + requests, com `timeout=10` em todas as requisições.
- Endpoints deduzidos da API pública restful-booker: POST /booking (criação), GET /booking/{id} (consulta), GET /booking com query `firstname` e `lastname` (listagem), POST /auth (token) e DELETE /booking/{id} (remoção).
- Payload usa os nomes de campo da API: `firstname`, `lastname`, `totalprice` (inteiro), `depositpaid` (booleano), `bookingdates` com `checkin` e `checkout` no formato AAAA-MM-DD, e `additionalneeds` (string).
- Datas de teste são futuras (2027-03-10 a 2027-03-15) para evitar datas passadas.
- POST /booking responde 200 com `{"bookingid": <int>, "booking": {...}}`, onde `booking` tem os mesmos campos enviados.
- GET /booking/{id} responde 200 com o objeto da reserva, sem `bookingid`. Para id inexistente ou 0, responde 404.
- GET /booking com filtros responde 200 com lista de objetos `{"bookingid": <int>}`. Sem correspondência, retorna lista vazia.
- Nomes únicos são gerados com UUID para evitar colisão entre execuções.
- Com `totalprice` 0 e `depositpaid` false (CT08), assumo que a API aceita e devolve os mesmos valores.
- Nomes com acentos e caracteres especiais (CT06) são preservados sem alteração na ida e na volta em UTF-8.
- Credenciais `admin` / `password123` são as da conta pública de exemplo da API. Elas são usadas apenas para remover as reservas criadas pelos testes, via DELETE com cookie `token`.
- Limpeza: as reservas criadas são removidas no teardown do fixture `ids_para_remover`.
- Validações negativas de criação (campos ausentes ou inválidos) não aparecem nos critérios de aceitação, então não foram cobertas.
- Não verifiquei se o host `restful-booker.herokuapp.com` está disponível, pois não tenho acesso à internet. Se estiver fora do ar, os testes falharão por conexão, não por defeito funcional.

## SCRIPT

```python
import uuid

import pytest
import requests

BASE_URL = "https://restful-booker.herokuapp.com"
USERNAME = "admin"
PASSWORD = "password123"
TIMEOUT = 10
HEADERS = {"Content-Type": "application/json", "Accept": "application/json"}


def _dados_reserva(**alteracoes):
    dados = {
        "firstname": "Joao",
        "lastname": "Silva",
        "totalprice": 150,
        "depositpaid": True,
        "bookingdates": {"checkin": "2027-03-10", "checkout": "2027-03-15"},
        "additionalneeds": "Cafe da manha",
    }
    dados.update(alteracoes)
    return dados


def _nome_unico():
    return f"Nome{uuid.uuid4().hex[:10]}"


def _criar_reserva(dados):
    return requests.post(f"{BASE_URL}/booking", json=dados, headers=HEADERS, timeout=TIMEOUT)


def _consultar_reserva(booking_id):
    return requests.get(f"{BASE_URL}/booking/{booking_id}", headers=HEADERS, timeout=TIMEOUT)


def _remover_reserva(booking_id):
    token = requests.post(
        f"{BASE_URL}/auth",
        json={"username": USERNAME, "password": PASSWORD},
        headers=HEADERS,
        timeout=TIMEOUT,
    ).json()["token"]
    requests.delete(
        f"{BASE_URL}/booking/{booking_id}",
        headers={"Cookie": f"token={token}"},
        timeout=TIMEOUT,
    )


@pytest.fixture
def ids_para_remover():
    ids = []
    yield ids
    for booking_id in ids:
        _remover_reserva(booking_id)


def test_ct01_criar_reserva_com_dados_validos_retorna_200_e_dados_iguais(ids_para_remover):
    dados = _dados_reserva(firstname=_nome_unico(), lastname=_nome_unico())

    resposta = _criar_reserva(dados)

    assert resposta.status_code == 200
    corpo = resposta.json()
    ids_para_remover.append(corpo["bookingid"])
    assert isinstance(corpo["bookingid"], int)
    assert corpo["booking"] == dados


def test_ct02_consultar_reserva_criada_retorna_todos_os_campos_iguais(ids_para_remover):
    dados = _dados_reserva(firstname=_nome_unico(), lastname=_nome_unico())
    booking_id = _criar_reserva(dados).json()["bookingid"]
    ids_para_remover.append(booking_id)

    resposta = _consultar_reserva(booking_id)

    assert resposta.status_code == 200
    assert resposta.json() == dados


def test_ct03_consultar_id_inexistente_retorna_404():
    resposta = _consultar_reserva(99999999)

    assert resposta.status_code == 404


def test_ct04_listar_por_nome_e_sobrenome_contem_id_criado(ids_para_remover):
    dados = _dados_reserva(firstname=_nome_unico(), lastname=_nome_unico())
    booking_id = _criar_reserva(dados).json()["bookingid"]
    ids_para_remover.append(booking_id)

    resposta = requests.get(
        f"{BASE_URL}/booking",
        params={"firstname": dados["firstname"], "lastname": dados["lastname"]},
        headers=HEADERS,
        timeout=TIMEOUT,
    )

    assert resposta.status_code == 200
    assert booking_id in [item["bookingid"] for item in resposta.json()]


def test_ct05_listar_por_nome_inexistente_retorna_lista_vazia():
    resposta = requests.get(
        f"{BASE_URL}/booking",
        params={"firstname": _nome_unico(), "lastname": _nome_unico()},
        headers=HEADERS,
        timeout=TIMEOUT,
    )

    assert resposta.status_code == 200
    assert resposta.json() == []


def test_ct06_consultar_reserva_com_caracteres_especiais_retorna_dados_iguais(ids_para_remover):
    dados = _dados_reserva(
        firstname="José Ângela",
        lastname="D'Ávila-Müller",
        additionalneeds="Berço & cadeira de rodas",
    )
    booking_id = _criar_reserva(dados).json()["bookingid"]
    ids_para_remover.append(booking_id)

    resposta = _consultar_reserva(booking_id)

    assert resposta.status_code == 200
    assert resposta.json() == dados


def test_ct07_consultar_id_zero_retorna_404():
    resposta = _consultar_reserva(0)

    assert resposta.status_code == 404


def test_ct08_criar_reserva_com_preco_zero_e_sem_deposito_retorna_dados_iguais(ids_para_remover):
    dados = _dados_reserva(
        firstname=_nome_unico(),
        lastname=_nome_unico(),
        totalprice=0,
        depositpaid=False,
    )

    resposta = _criar_reserva(dados)

    assert resposta.status_code == 200
    corpo = resposta.json()
    ids_para_remover.append(corpo["bookingid"])
    assert isinstance(corpo["bookingid"], int)
    assert corpo["booking"] == dados
```

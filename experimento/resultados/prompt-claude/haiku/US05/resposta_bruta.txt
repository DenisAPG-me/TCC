## CASOS DE TESTE

| ID | Título | Tipo | Critério de Aceitação | Passos | Resultado Esperado |
|----|--------|------|-----------------------|--------|--------------------|
| CT01 | Login com usuário e senha vazios | Negativo | CA1 | Acessar /admin; deixar usuário e senha vazios; clicar em Login | Exibe "Invalid credentials" e permanece na tela de login |
| CT02 | Login com usuário admin e senha incorreta | Negativo | CA2 | Acessar /admin; informar usuário "admin"; informar senha "senha_incorreta"; clicar em Login | Exibe "Invalid credentials" e permanece na tela de login |
| CT03 | Login com senha preenchida e usuário vazio | Borda | CA1 | Acessar /admin; deixar usuário vazio; informar senha "password"; clicar em Login | Exibe "Invalid credentials" e permanece na tela de login |
| CT04 | Login com senha em caixa diferente | Borda | CA2 | Acessar /admin; informar usuário "admin"; informar senha "PASSWORD"; clicar em Login | Exibe "Invalid credentials" e permanece na tela de login |
| CT05 | Login com credenciais válidas | Positivo | CA3 | Acessar /admin; informar usuário "admin"; informar senha "password"; clicar em Login | Redireciona para /admin/rooms; lista exibe o quarto 101 do tipo Single; menu exibe Rooms, Report, Branding e Messages |
| CT06 | Logout retorna à home pública | Positivo | CA4 | Autenticar com admin/password; clicar em Logout | URL volta para https://automationintesting.online/ sem formulário de login |
| CT07 | Acesso direto à lista de quartos após logout | Negativo | CA5 | Autenticar com admin/password; clicar em Logout; acessar /admin/rooms diretamente | Exibe a tela de login; a lista de quartos não é exibida |

## SUPOSIÇÕES

- Tecnologia: Python + pytest + pytest-playwright, pois a User Story é de interface web. Os testes usam a fixture `page` do plugin, sem fixture própria de browser e sem `sync_playwright()`. O Chromium headless é o padrão do plugin.
- Base URL: constante `BASE_URL = "https://automationintesting.online"`.
- Tela de login em `/admin`, com campos rotulados "Username" e "Password" (`get_by_label`) e botão "Login" (`get_by_role("button")`).
- O formulário não usa atributo `required`, então clicar em Login com campos vazios envia a requisição e o servidor retorna a mensagem de erro.
- A mensagem "Invalid credentials" aparece como texto na própria tela de login, sem redirecionamento.
- Login válido redireciona para `/admin/rooms`.
- A lista de quartos é uma tabela, e a linha do quarto 101 contém os textos "101" e "Single".
- O menu contém links (`get_by_role("link")`) com nomes exatos Rooms, Report, Branding e Messages.
- O link "Logout" fica no menu e é acessível por `get_by_role("link")`.
- Após logout, o sistema redireciona para a home pública `https://automationintesting.online/`, que não exibe campo "Username".
- A verificação de senha diferencia maiúsculas de minúsculas (CT04).
- Dados de teste: senha incorreta `senha_incorreta`; usuário vazio como string vazia.
- Sessão não persiste após logout: acessar `/admin/rooms` diretamente redireciona para a tela de login (CT07).
- Cada teste recebe uma `page` nova do plugin, com contexto isolado, o que garante independência entre os testes.

## SCRIPT

```python
import re

from playwright.sync_api import Page, expect

BASE_URL = "https://automationintesting.online"
USUARIO_ADMIN = "admin"
SENHA_ADMIN = "password"
SENHA_INCORRETA = "senha_incorreta"
MENSAGEM_ERRO_LOGIN = "Invalid credentials"
QUARTO_ESPERADO = "101"
TIPO_QUARTO_ESPERADO = "Single"
MENU_ESPERADO = ["Rooms", "Report", "Branding", "Messages"]


def _abrir_login(page: Page) -> None:
    page.goto(f"{BASE_URL}/admin")
    expect(page.get_by_label("Username")).to_be_visible()


def _submeter_login(page: Page, usuario: str, senha: str) -> None:
    page.get_by_label("Username").fill(usuario)
    page.get_by_label("Password").fill(senha)
    page.get_by_role("button", name="Login").click()


def _fazer_login(page: Page) -> None:
    _abrir_login(page)
    _submeter_login(page, USUARIO_ADMIN, SENHA_ADMIN)
    expect(page).to_have_url(re.compile(r"/admin/rooms"))


def _fazer_logout(page: Page) -> None:
    page.get_by_role("link", name="Logout").click()
    expect(page).to_have_url(re.compile(rf"^{re.escape(BASE_URL)}/?$"))


def test_ct01_login_com_usuario_e_senha_vazios(page: Page) -> None:
    _abrir_login(page)
    _submeter_login(page, "", "")
    expect(page.get_by_text(MENSAGEM_ERRO_LOGIN)).to_be_visible()
    expect(page.get_by_label("Username")).to_be_visible()
    expect(page).to_have_url(re.compile(r"/admin/?$"))


def test_ct02_login_com_senha_incorreta(page: Page) -> None:
    _abrir_login(page)
    _submeter_login(page, USUARIO_ADMIN, SENHA_INCORRETA)
    expect(page.get_by_text(MENSAGEM_ERRO_LOGIN)).to_be_visible()
    expect(page.get_by_label("Username")).to_be_visible()
    expect(page).to_have_url(re.compile(r"/admin/?$"))


def test_ct03_login_com_senha_e_usuario_vazio(page: Page) -> None:
    _abrir_login(page)
    _submeter_login(page, "", SENHA_ADMIN)
    expect(page.get_by_text(MENSAGEM_ERRO_LOGIN)).to_be_visible()
    expect(page.get_by_label("Username")).to_be_visible()
    expect(page).to_have_url(re.compile(r"/admin/?$"))


def test_ct04_login_com_senha_em_caixa_diferente(page: Page) -> None:
    _abrir_login(page)
    _submeter_login(page, USUARIO_ADMIN, SENHA_ADMIN.upper())
    expect(page.get_by_text(MENSAGEM_ERRO_LOGIN)).to_be_visible()
    expect(page.get_by_label("Username")).to_be_visible()
    expect(page).to_have_url(re.compile(r"/admin/?$"))


def test_ct05_login_com_credenciais_validas(page: Page) -> None:
    _abrir_login(page)
    _submeter_login(page, USUARIO_ADMIN, SENHA_ADMIN)
    expect(page).to_have_url(re.compile(r"/admin/rooms"))
    expect(
        page.get_by_role("row")
        .filter(has_text=QUARTO_ESPERADO)
        .filter(has_text=TIPO_QUARTO_ESPERADO)
    ).to_be_visible()
    for item in MENU_ESPERADO:
        expect(page.get_by_role("link", name=item, exact=True)).to_be_visible()


def test_ct06_logout_retorna_home_publica(page: Page) -> None:
    _fazer_login(page)
    _fazer_logout(page)
    expect(page.get_by_label("Username")).to_have_count(0)


def test_ct07_acesso_direto_lista_quartos_apos_logout(page: Page) -> None:
    _fazer_login(page)
    _fazer_logout(page)
    page.goto(f"{BASE_URL}/admin/rooms")
    expect(page.get_by_label("Username")).to_be_visible()
    expect(page).not_to_have_url(re.compile(r"/admin/rooms"))
```

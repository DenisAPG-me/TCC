## CASOS DE TESTE

| ID | Título | Tipo | Critério de Aceitação | Passos | Resultado Esperado |
|----|--------|------|-----------------------|--------|--------------------|
| CT01 | Adicionar 3 unidades de Claw Hammer ao carrinho | Positivo | CA1 | Abrir página do produto "Claw Hammer"; informar quantidade 3; clicar em "Add to cart" | Exibe "Product added to shopping cart."; indicador do carrinho mostra 3 |
| CT02 | Total da linha e total do carrinho com 3 unidades | Positivo | CA2 | Abrir página do produto "Claw Hammer"; registrar preço unitário; adicionar 3 unidades; abrir carrinho | Total da linha é igual a preço unitário × 3; total do carrinho é igual ao total da linha |
| CT03 | Alterar quantidade no carrinho de 3 para 1 | Positivo | CA3 | Adicionar 3 unidades de "Claw Hammer"; abrir carrinho; alterar quantidade para 1; atualizar | Total do carrinho é igual ao preço unitário |
| CT04 | Adicionar com quantidade padrão | Borda | CA1 | Abrir página do produto "Claw Hammer"; não alterar a quantidade; clicar em "Add to cart" | Exibe "Product added to shopping cart."; indicador do carrinho mostra 1 |
| CT05 | Adicionar 3 unidades de Thor Hammer | Negativo | CA4 | Abrir página do produto "Thor Hammer"; informar quantidade 3; clicar em "Add to cart" | Exibe "You can only have one Thor Hammer in the cart." |
| CT06 | Adicionar 1 unidade de Thor Hammer (limite permitido) | Borda | CA4 | Abrir página do produto "Thor Hammer"; informar quantidade 1; clicar em "Add to cart" | Exibe "Product added to shopping cart."; indicador do carrinho mostra 1; mensagem de limite não é exibida |

## SUPOSIÇÕES

- Tecnologia: Python + pytest + pytest-playwright (UI), pois os critérios de aceitação são de interface web. Instalação prevista: `pip install pytest pytest-playwright` e `playwright install chromium`.
- Fixture `page` fornecida pelo plugin pytest-playwright; o navegador é Chromium headless por padrão do plugin. Nenhuma fixture própria de browser é criada.
- Acesso sem login: o carrinho de visitante é usado nos testes.
- Isolamento: cada teste roda em um contexto novo do plugin, portanto o carrinho começa vazio em cada caso.
- Busca de produto: campo de busca com placeholder "Search", seguido de Enter e clique no título exato do produto (heading) na lista de resultados.
- Campo de quantidade na página do produto: label "Quantity".
- Botão de adicionar: role button com nome "Add to cart".
- Mensagem de confirmação: texto "Product added to shopping cart.", exibida em toast/alerta.
- Indicador do carrinho: texto dentro do link de navegação "Cart", que exibe a quantidade total de itens.
- Preço unitário na página do produto: elemento `[data-test='unit-price']`.
- Página do carrinho: acessada pelo link "Cart". Nela, a quantidade da linha usa `[data-test='product-quantity']`, o total da linha usa `[data-test='line-price']` e o total do carrinho usa `[data-test='cart-total']`.
- Atualização da quantidade no carrinho: preencher o campo e clicar no botão "Update".
- Formato de preço: valor numérico com ponto ou vírgula decimal, possivelmente precedido por "$". Comparações usam `Decimal`.
- Limite de quantidade: apenas o Thor Hammer tem a restrição de uma unidade (CA4). Não há limite máximo para os demais produtos descrito na User Story.
- Dados de teste: "Claw Hammer" com quantidades 1 e 3; "Thor Hammer" com quantidades 1 e 3.
- Os seletores `data-test` são usados onde não há role ou label recomendado e precisam ser validados contra a página real.

## SCRIPT

```python
import re
from decimal import Decimal

from playwright.sync_api import Page, expect

BASE_URL = "https://practicesoftwaretesting.com/"
PRODUTO_CLAW_HAMMER = "Claw Hammer"
PRODUTO_THOR_HAMMER = "Thor Hammer"
MSG_ADICIONADO = "Product added to shopping cart."
MSG_LIMITE_THOR = "You can only have one Thor Hammer in the cart."


def abrir_produto(page: Page, nome: str) -> None:
    page.goto(BASE_URL)
    campo_busca = page.get_by_placeholder("Search")
    campo_busca.fill(nome)
    campo_busca.press("Enter")
    page.get_by_role("heading", name=nome, exact=True).click()
    expect(page.get_by_role("heading", name=nome, exact=True)).to_be_visible()


def adicionar_ao_carrinho(page: Page, quantidade: int) -> None:
    page.get_by_label("Quantity").fill(str(quantidade))
    page.get_by_role("button", name="Add to cart").click()


def abrir_carrinho(page: Page) -> None:
    page.get_by_role("link", name=re.compile("Cart")).click()


def verificar_indicador_carrinho(page: Page, valor: str) -> None:
    expect(page.get_by_role("link", name=re.compile("Cart"))).to_contain_text(valor)


def ler_preco(localizador) -> Decimal:
    texto = localizador.inner_text()
    numero = re.search(r"\d+(?:[.,]\d+)?", texto).group()
    return Decimal(numero.replace(",", "."))


def test_ct01_adicionar_3_unidades_claw_hammer_ao_carrinho(page: Page):
    abrir_produto(page, PRODUTO_CLAW_HAMMER)
    adicionar_ao_carrinho(page, 3)
    expect(page.get_by_text(MSG_ADICIONADO)).to_be_visible()
    verificar_indicador_carrinho(page, "3")


def test_ct02_total_da_linha_e_do_carrinho_com_3_unidades(page: Page):
    abrir_produto(page, PRODUTO_CLAW_HAMMER)
    preco_unitario = ler_preco(page.locator("[data-test='unit-price']"))
    adicionar_ao_carrinho(page, 3)
    expect(page.get_by_text(MSG_ADICIONADO)).to_be_visible()
    abrir_carrinho(page)
    total_linha = ler_preco(page.locator("[data-test='line-price']"))
    total_carrinho = ler_preco(page.locator("[data-test='cart-total']"))
    assert total_linha == preco_unitario * 3
    assert total_carrinho == total_linha


def test_ct03_alterar_quantidade_no_carrinho_de_3_para_1(page: Page):
    abrir_produto(page, PRODUTO_CLAW_HAMMER)
    preco_unitario = ler_preco(page.locator("[data-test='unit-price']"))
    adicionar_ao_carrinho(page, 3)
    expect(page.get_by_text(MSG_ADICIONADO)).to_be_visible()
    abrir_carrinho(page)
    total = page.locator("[data-test='cart-total']")
    texto_antes = total.inner_text()
    page.locator("[data-test='product-quantity']").fill("1")
    page.get_by_role("button", name="Update").click()
    expect(total).not_to_have_text(texto_antes)
    assert ler_preco(total) == preco_unitario


def test_ct04_adicionar_com_quantidade_padrao(page: Page):
    abrir_produto(page, PRODUTO_CLAW_HAMMER)
    page.get_by_role("button", name="Add to cart").click()
    expect(page.get_by_text(MSG_ADICIONADO)).to_be_visible()
    verificar_indicador_carrinho(page, "1")


def test_ct05_adicionar_3_unidades_thor_hammer_exibe_limite(page: Page):
    abrir_produto(page, PRODUTO_THOR_HAMMER)
    adicionar_ao_carrinho(page, 3)
    expect(page.get_by_text(MSG_LIMITE_THOR)).to_be_visible()


def test_ct06_adicionar_1_unidade_thor_hammer_no_limite_permitido(page: Page):
    abrir_produto(page, PRODUTO_THOR_HAMMER)
    adicionar_ao_carrinho(page, 1)
    expect(page.get_by_text(MSG_ADICIONADO)).to_be_visible()
    expect(page.get_by_text(MSG_LIMITE_THOR)).to_have_count(0)
    verificar_indicador_carrinho(page, "1")
```

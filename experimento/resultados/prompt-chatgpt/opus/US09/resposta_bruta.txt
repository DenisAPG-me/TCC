CASOS DE TESTE

| ID | título | tipo | critério de aceitação relacionado | passos resumidos | resultado esperado |
|---|---|---|---|---|---|
| CT001 | Excluir reserva sem token é negado | negativo | CA01 | Criar reserva; enviar DELETE /booking/{id} sem cookie nem cabeçalho de autorização; consultar GET /booking/{id} | DELETE retorna 403; GET retorna 200 com os mesmos dados da reserva criada |
| CT002 | Excluir reserva com token inválido é negado | negativo | CA02 | Criar reserva; enviar DELETE /booking/{id} com Cookie token=valor aleatório inexistente; consultar GET /booking/{id} | DELETE retorna 403; GET retorna 200 com os mesmos dados da reserva criada |
| CT003 | Excluir reserva com token vazio é negado | borda | CA02 | Criar reserva; enviar DELETE /booking/{id} com Cookie token= (valor vazio); consultar GET /booking/{id} | DELETE retorna 403; GET retorna 200 com os mesmos dados da reserva criada |
| CT004 | Excluir reserva com token válido | positivo | CA03 | Autenticar em POST /auth com admin/password123; criar reserva; enviar DELETE /booking/{id} com Cookie token=token obtido | POST /auth retorna 200 com token não vazio; DELETE retorna 201 |
| CT005 | Consultar reserva excluída retorna 404 | positivo | CA04 | Autenticar; criar reserva; excluir com token válido (201); consultar GET /booking/{id} | GET retorna 404 |
| CT006 | Excluir novamente reserva já excluída | negativo | CA05 | Autenticar; criar reserva alvo e reserva de controle; excluir a alvo (201); repetir DELETE na alvo com token válido; consultar alvo e controle | Segunda exclusão retorna status entre 400 e 499; alvo continua 404; controle retorna 200 com dados inalterados |
| CT007 | Filtro por nome único não retorna reserva excluída | positivo | CA06 | Criar reserva com firstname e lastname únicos; confirmar que GET /booking?firstname=...&lastname=... contém o id; excluir com token válido (201); repetir o filtro | Filtro final retorna 200 e lista vazia |

SUPOSIÇÕES

1. Explícito na User Story: URL base `https://restful-booker.herokuapp.com`, credenciais `admin` / `password123`, e os status 403, 200, 201, 404 e 4xx dos critérios. Os critérios não possuem identificadores; foram mapeados na ordem de apresentação: critério 1 = CA01, 2 = CA02, 3 = CA03, 4 = CA04, 5 = CA05, 6 = CA06.
2. Inferido: a autenticação é feita por `POST /auth` com JSON `{"username", "password"}`, retornando 200 e corpo `{"token": "<valor>"}`. Afeta CT004 a CT007 e a limpeza.
3. Inferido: o token é enviado no cabeçalho `Cookie: token=<valor>`. Nenhum cabeçalho `Authorization` é enviado nos testes. Afeta todos os casos.
4. Inferido: a criação usa `POST /booking` com JSON contendo `firstname`, `lastname`, `totalprice`, `depositpaid`, `bookingdates` (`checkin`, `checkout` em `AAAA-MM-DD`) e `additionalneeds`. A resposta é 200 com `{"bookingid": <int>, "booking": {...}}`. Afeta todos os casos.
5. Inferido: `GET /booking/{id}` retorna 200 e os mesmos campos enviados na criação. "Continua consultável/existindo" foi verificado como status 200 e corpo igual ao payload criado. Afeta CT001, CT002, CT003 e CT006.
6. Inferido: a exclusão usa `DELETE /booking/{id}`, e a listagem filtrada usa `GET /booking?firstname=...&lastname=...`, retornando uma lista JSON de objetos com `bookingid`. Afeta CT004 a CT007.
7. Explícito apenas como "status de erro 4xx": o status exato da segunda exclusão não é especificado. Por isso CT006 verifica somente a faixa 400 a 499. "Nenhuma outra reserva é afetada" foi interpretado como uma reserva de controle, criada no mesmo teste, que permanece com 200 e dados inalterados.
8. Inferido: CT003, com token vazio, é um caso de borda derivado de "token inválido" (CA02). O status 403 esperado decorre desse critério e não de regra adicional.
9. Inferido: o nome único de CT007 é obtido com sufixo `uuid4` em `firstname` e `lastname`. Assume-se que o filtro reflete a criação e a exclusão de forma imediata. Antes da exclusão, o teste confirma que o filtro encontra a reserva, para que a lista vazia não seja um falso positivo.
10. Ambiente: o sistema é um ambiente público de demonstração compartilhado. Requer acesso de rede e pode ser reiniciado por terceiros; essa é uma pré-condição externa inevitável. Cada teste cria seus próprios dados. Na limpeza, uma reserva ainda existente (GET 200) é excluída com token válido, e a limpeza exige 201.
11. Os critérios tratam apenas de API REST. Por isso não há testes de UI, e os requisitos de pytest-playwright, `page`, `expect` e locators não se aplicam; não há dependência de Playwright no arquivo. A URL base fica centralizada na constante `BASE_URL`.
12. Não há caso adicional de borda para CA01, CA03, CA04 e CA06, pois a User Story não define limites (formatos de id, tamanhos de nome etc.) que justifiquem variações sem inventar regras.
13. Os valores inferidos (rotas, cabeçalhos, payload, timeout de 30 s) estão centralizados em constantes no topo do arquivo e podem exigir ajuste no sistema real. O código ser executável não comprova compatibilidade com o sistema.

```python
import uuid

import pytest
import requests

BASE_URL = "https://restful-booker.herokuapp.com"
AUTH_PATH = "/auth"
BOOKING_PATH = "/booking"
USERNAME = "admin"
PASSWORD = "password123"
TIMEOUT = 30
JSON_HEADERS = {"Content-Type": "application/json", "Accept": "application/json"}


def booking_url(booking_id=None):
    if booking_id is None:
        return f"{BASE_URL}{BOOKING_PATH}"
    return f"{BASE_URL}{BOOKING_PATH}/{booking_id}"


def build_payload():
    suffix = uuid.uuid4().hex[:12]
    return {
        "firstname": f"Teste{suffix}",
        "lastname": f"Exclusao{suffix}",
        "totalprice": 150,
        "depositpaid": True,
        "bookingdates": {"checkin": "2026-11-10", "checkout": "2026-11-15"},
        "additionalneeds": "Breakfast",
    }


def auth_cookie(token):
    return {"Accept": "application/json", "Cookie": f"token={token}"}


def get_booking(booking_id):
    return requests.get(booking_url(booking_id), headers={"Accept": "application/json"}, timeout=TIMEOUT)


def delete_booking(booking_id, headers):
    return requests.delete(booking_url(booking_id), headers=headers, timeout=TIMEOUT)


def obtain_token():
    response = requests.post(
        f"{BASE_URL}{AUTH_PATH}",
        json={"username": USERNAME, "password": PASSWORD},
        headers=JSON_HEADERS,
        timeout=TIMEOUT,
    )
    assert response.status_code == 200, response.text
    token = response.json().get("token")
    assert isinstance(token, str) and token, response.text
    return token


@pytest.fixture
def token():
    return obtain_token()


@pytest.fixture
def create_booking():
    created_ids = []

    def _create():
        payload = build_payload()
        response = requests.post(booking_url(), json=payload, headers=JSON_HEADERS, timeout=TIMEOUT)
        assert response.status_code == 200, response.text
        body = response.json()
        booking_id = body["bookingid"]
        assert isinstance(booking_id, int)
        assert body["booking"] == payload
        created_ids.append(booking_id)
        return booking_id, payload

    yield _create

    if created_ids:
        cleanup_token = obtain_token()
        for booking_id in created_ids:
            if get_booking(booking_id).status_code == 200:
                response = delete_booking(booking_id, auth_cookie(cleanup_token))
                assert response.status_code == 201, response.text


def assert_booking_unchanged(booking_id, payload):
    response = get_booking(booking_id)
    assert response.status_code == 200, response.text
    assert response.json() == payload


def test_CT001_excluir_sem_token_retorna_403_e_reserva_permanece(create_booking):
    booking_id, payload = create_booking()

    response = delete_booking(booking_id, {"Accept": "application/json"})

    assert response.status_code == 403, response.text
    assert_booking_unchanged(booking_id, payload)


def test_CT002_excluir_com_token_invalido_retorna_403_e_reserva_permanece(create_booking):
    booking_id, payload = create_booking()
    invalid_token = f"token-invalido-{uuid.uuid4().hex}"

    response = delete_booking(booking_id, auth_cookie(invalid_token))

    assert response.status_code == 403, response.text
    assert_booking_unchanged(booking_id, payload)


def test_CT003_excluir_com_token_vazio_retorna_403_e_reserva_permanece(create_booking):
    booking_id, payload = create_booking()

    response = delete_booking(booking_id, auth_cookie(""))

    assert response.status_code == 403, response.text
    assert_booking_unchanged(booking_id, payload)


def test_CT004_excluir_com_token_valido_retorna_201(create_booking, token):
    booking_id, _ = create_booking()

    response = delete_booking(booking_id, auth_cookie(token))

    assert response.status_code == 201, response.text


def test_CT005_consultar_reserva_excluida_retorna_404(create_booking, token):
    booking_id, _ = create_booking()
    delete_response = delete_booking(booking_id, auth_cookie(token))
    assert delete_response.status_code == 201, delete_response.text

    response = get_booking(booking_id)

    assert response.status_code == 404, response.text


def test_CT006_excluir_novamente_retorna_4xx_sem_afetar_outra_reserva(create_booking, token):
    target_id, _ = create_booking()
    control_id, control_payload = create_booking()
    first_delete = delete_booking(target_id, auth_cookie(token))
    assert first_delete.status_code == 201, first_delete.text

    second_delete = delete_booking(target_id, auth_cookie(token))

    assert 400 <= second_delete.status_code <= 499, second_delete.status_code
    assert get_booking(target_id).status_code == 404
    assert_booking_unchanged(control_id, control_payload)


def test_CT007_filtro_por_nome_unico_nao_retorna_reserva_excluida(create_booking, token):
    booking_id, payload = create_booking()
    params = {"firstname": payload["firstname"], "lastname": payload["lastname"]}

    before = requests.get(booking_url(), params=params, headers={"Accept": "application/json"}, timeout=TIMEOUT)
    assert before.status_code == 200, before.text
    assert booking_id in [item["bookingid"] for item in before.json()]

    delete_response = delete_booking(booking_id, auth_cookie(token))
    assert delete_response.status_code == 201, delete_response.text

    after = requests.get(booking_url(), params=params, headers={"Accept": "application/json"}, timeout=TIMEOUT)

    assert after.status_code == 200, after.text
    assert after.json() == []
```

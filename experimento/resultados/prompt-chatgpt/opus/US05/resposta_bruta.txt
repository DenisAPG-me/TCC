|---|---|---|---|---|---|

SUPOSIÇÕES

1. Explícito: os critérios de aceitação não têm identificadores. Atribuí CA01 a CA05 na ordem apresentada: CA01 = credenciais vazias; CA02 = admin com senha incorreta; CA03 = login válido, quarto 101 Single e menu; CA04 = Logout leva à página inicial; CA05 = após logout, acesso direto à lista de quartos mostra o login.
2. Conflito de instruções: as regras iniciais proíbem pytest-playwright e exigem `sync_playwright()`. A seção "REQUISITOS TÉCNICOS OBRIGATÓRIOS" determina o contrário e declara que prevalece em caso de conflito. Por isso o arquivo usa o plugin pytest-playwright, que fornece a fixture `page` e um contexto novo por teste, além de `expect` de `playwright.sync_api`. Não há fixture própria de browser ou page, nem chamada a `sync_playwright()`. Assume-se que o plugin está instalado, com o navegador Chromium padrão em modo headless.
3. Base URL: vem da opção `--base-url` (fixture `base_url` do pytest-base-url, dependência do pytest-playwright). Na ausência da opção, usa a constante `BASE_URL = "https://automationintesting.online/"`.
4. Explícito: o painel fica em /admin e a conta de demonstração é admin / password. Inferido: a lista de quartos do painel fica em /admin/rooms, e o login válido redireciona para ela. CT004 e CT006 dependem dessa rota (constante `ROOMS_PATH`).
5. Inferidos os seletores da tela de login: campos com rótulos acessíveis "Username" e "Password", e botão com nome acessível "Login". Afeta CT001 a CT006.
6. Explícito: o texto "Invalid credentials". Inferido: ele aparece como texto visível na própria tela de login, sem navegação. Afeta CT001 a CT003.
7. Inferido: em CA01, "continuo na tela de login" é verificado pela URL que permanece em /admin e pela presença do formulário. Em CT003, apenas pela presença do formulário, pois CA02 não fala de permanência na URL.
8. Inferidos os elementos do menu autenticado: os itens Rooms, Report, Branding e Messages são links com esses nomes acessíveis, e Logout é um botão com nome "Logout". Afeta CT002 e CT004 a CT006.
9. Inferido: cada quarto da lista do painel é um elemento com `data-testid="roomlisting"`, e o número do quarto aparece como texto exato "101". A verificação do tipo "Single" ignora maiúsculas e minúsculas, pois o sistema pode exibir "single". Afeta CT004 e CT006.
10. Inferido: a "página inicial pública" corresponde à raiz da URL base ("/"). Esse é o único marcador usado, para não depender de textos institucionais não especificados. Afeta CT005.
11. Pré-condição externa inevitável: o ambiente de demonstração é compartilhado e deve conter o quarto 101 do tipo Single, com a conta admin / password ativa. Não há criação nem limpeza de dados, pois os testes não alteram dados. A independência entre os testes vem do contexto de navegador novo que o plugin cria para cada teste.
12. CT003 (senha vazia) foi classificado como borda de CA02. Não foram criados casos com limites de tamanho, maiúsculas e minúsculas ou espaços, porque a User Story não especifica essas regras e criá-los exigiria inventar comportamento.
13. A User Story não pede testes de API REST. Por isso o arquivo contém apenas testes de interface web, e requests não é utilizado.
14. Inferido: timeout de 10 segundos para as asserções `expect`, por se tratar de um ambiente público remoto. O valor está na constante `UI_TIMEOUT_MS`.
15. O código pode exigir ajustes nos valores inferidos, centralizados nas constantes do topo do arquivo, antes de funcionar no sistema real. O arquivo é sintaticamente executável, mas a compatibilidade com o sistema não foi comprovada.

```python
import re

import pytest
from playwright.sync_api import Page, expect

# URL base (pode ser sobrescrita com --base-url)
BASE_URL = "https://automationintesting.online/"

# Rotas (ROOMS_PATH é inferida)
ADMIN_PATH = "/admin"
ROOMS_PATH = "/admin/rooms"

# Credenciais
VALID_USERNAME = "admin"
VALID_PASSWORD = "password"
WRONG_PASSWORD = "senha-incorreta-123"

# Seletores e textos inferidos
USERNAME_LABEL = "Username"
PASSWORD_LABEL = "Password"
LOGIN_BUTTON_NAME = "Login"
LOGOUT_BUTTON_NAME = "Logout"
INVALID_CREDENTIALS_TEXT = "Invalid credentials"
MENU_LINKS = ("Rooms", "Report", "Branding", "Messages")
ROOM_LISTING_TEST_ID = "roomlisting"
ROOM_NUMBER = "101"
ROOM_TYPE = "Single"

UI_TIMEOUT_MS = 10_000
expect.set_options(timeout=UI_TIMEOUT_MS)


@pytest.fixture
def app_root(base_url):
    return (base_url or BASE_URL).rstrip("/")


def username_input(page: Page):
    return page.get_by_label(USERNAME_LABEL, exact=True)


def password_input(page: Page):
    return page.get_by_label(PASSWORD_LABEL, exact=True)


def login_button(page: Page):
    return page.get_by_role("button", name=LOGIN_BUTTON_NAME, exact=True)


def logout_button(page: Page):
    return page.get_by_role("button", name=LOGOUT_BUTTON_NAME, exact=True)


def room_listings(page: Page):
    return page.get_by_test_id(ROOM_LISTING_TEST_ID)


def expect_login_screen(page: Page):
    expect(username_input(page)).to_be_visible()
    expect(password_input(page)).to_be_visible()
    expect(login_button(page)).to_be_visible()


def open_login(page: Page, app_root: str):
    page.goto(app_root + ADMIN_PATH)
    expect_login_screen(page)


def submit_login(page: Page, username: str, password: str):
    username_input(page).fill(username)
    password_input(page).fill(password)
    login_button(page).click()


def login_as_admin(page: Page, app_root: str):
    open_login(page, app_root)
    submit_login(page, VALID_USERNAME, VALID_PASSWORD)
    expect(page).to_have_url(re.compile(re.escape(ROOMS_PATH) + r"/?$"))
    expect(logout_button(page)).to_be_visible()


def logout_to_home(page: Page, app_root: str):
    logout_button(page).click()
    expect(page).to_have_url(re.compile("^" + re.escape(app_root) + r"/?$"))


def test_CT001_login_com_usuario_e_senha_vazios(page: Page, app_root: str):
    open_login(page, app_root)

    submit_login(page, "", "")

    expect(page.get_by_text(INVALID_CREDENTIALS_TEXT)).to_be_visible()
    expect(page).to_have_url(re.compile(re.escape(ADMIN_PATH) + r"/?$"))
    expect_login_screen(page)


def test_CT002_login_com_admin_e_senha_incorreta(page: Page, app_root: str):
    open_login(page, app_root)

    submit_login(page, VALID_USERNAME, WRONG_PASSWORD)

    expect(page.get_by_text(INVALID_CREDENTIALS_TEXT)).to_be_visible()
    expect(logout_button(page)).to_have_count(0)


def test_CT003_login_com_admin_e_senha_vazia(page: Page, app_root: str):
    open_login(page, app_root)

    submit_login(page, VALID_USERNAME, "")

    expect(page.get_by_text(INVALID_CREDENTIALS_TEXT)).to_be_visible()
    expect_login_screen(page)


def test_CT004_login_valido_exibe_lista_de_quartos_e_menu(page: Page, app_root: str):
    login_as_admin(page, app_root)

    room_101 = room_listings(page).filter(has=page.get_by_text(ROOM_NUMBER, exact=True))
    expect(room_101.first).to_be_visible()
    expect(room_101.first).to_contain_text(re.compile(ROOM_TYPE, re.IGNORECASE))

    for link_name in MENU_LINKS:
        expect(page.get_by_role("link", name=link_name, exact=True)).to_be_visible()


def test_CT005_logout_retorna_a_pagina_inicial_publica(page: Page, app_root: str):
    login_as_admin(page, app_root)

    logout_to_home(page, app_root)

    expect(logout_button(page)).to_have_count(0)


def test_CT006_acesso_direto_a_lista_de_quartos_apos_logout(page: Page, app_root: str):
    login_as_admin(page, app_root)
    logout_to_home(page, app_root)

    page.goto(app_root + ROOMS_PATH)

    expect_login_screen(page)
    expect(room_listings(page)).to_have_count(0)
    expect(logout_button(page)).to_have_count(0)
```

CASOS DE TESTE

| ID | título | tipo | critério de aceitação relacionado | passos resumidos | resultado esperado |
|---|---|---|---|---|---|
| CT001 | Enviar mensagem válida pelo formulário | positivo | CA02 | Abrir a página inicial, preencher nome, assunto e dados de contato válidos e enviar | A confirmação exibida é `Thanks for getting in touch <nome>!` |
| CT002 | Contador aumenta após envio de mensagem | positivo | CA01, CA03 | Fazer login, anotar contador; enviar uma mensagem válida; fazer login novamente e consultar o contador | O contador é exatamente uma unidade maior que o valor anotado |
| CT003 | Mensagem enviada aparece na caixa de mensagens | positivo | CA04 | Enviar mensagem com nome e assunto únicos; abrir o painel e a caixa de mensagens | A lista contém o nome e o assunto enviados |
| CT004 | Acesso direto à caixa de mensagens após logout | negativo | CA05 | Fazer login, sair e abrir diretamente a rota da caixa de mensagens | O painel solicita login, exibindo formulário de autenticação |

SUPOSIÇÕES

1. Os critérios numerados na User Story não têm identificadores no formato CA. Para referência, foram mapeados em ordem: critério 1 → CA01, 2 → CA02, 3 → CA03, 4 → CA04 e 5 → CA05.
2. A URL base explícita é `https://automationintesting.online/`; a rota de login do painel é `/admin`, conforme a história. A rota de mensagens foi inferida como `/admin/messages`, e logout como `/admin/logout`. Os seletores e rotas inferidos podem precisar de ajuste antes do uso no sistema real.
3. O formulário inicial foi inferido como contendo campos acessíveis de nome, e-mail, telefone, assunto e mensagem, com botão de envio. Os nomes e assuntos são únicos por execução; o e-mail e telefone usados são valores plausíveis para dados válidos. O envio é considerado bem-sucedido quando aparece o texto de confirmação especificado.
4. O login foi inferido como um formulário com campos acessíveis `Username` e `Password`, credenciais explícitas na história (`admin` / `password`) e botão `Login`. O contador foi inferido como texto numérico visível junto ao item `Messages`; a extração lê o primeiro número associado ao item.
5. CT002 depende de que a aplicação persista mensagens entre sessões e de que não haja envios concorrentes que alterem o contador entre as leituras. CT003 depende de que a mensagem enviada permaneça disponível na caixa. CT004 depende de que `/admin/messages` exija sessão autenticada e que o logout invalide a sessão.
6. CT001–CT004 usam nomes e assuntos únicos para manter cada caso independente. O teste não tenta excluir mensagens, pois a história não descreve mecanismo de limpeza.
7. Não foi incluído caso negativo de formulário inválido: a história não especifica validações nem o resultado esperado para dados inválidos. Não foi incluído caso de borda, pois não há limites ou condições de fronteira definidos nos critérios.

```python
import re
import uuid

import pytest
from playwright.sync_api import expect


# Valores inferidos e centralizados para facilitar ajustes antes do uso real.
BASE_URL = "https://automationintesting.online/"
ADMIN_PATH = "/admin"
MESSAGES_PATH = "/admin/messages"
LOGOUT_PATH = "/admin/logout"
ADMIN_USERNAME = "admin"
ADMIN_PASSWORD = "password"
REQUEST_TIMEOUT_MS = 10_000


def unique_value(prefix):
    return f"{prefix}-{uuid.uuid4().hex[:10]}"


def fill_contact_form(page, name, subject):
    page.goto(BASE_URL)
    page.get_by_label(re.compile(r"name", re.IGNORECASE)).fill(name)
    page.get_by_label(re.compile(r"email", re.IGNORECASE)).fill(
        f"{unique_value('visitor')}@example.com"
    )
    page.get_by_label(re.compile(r"phone", re.IGNORECASE)).fill("+1 202 555 0147")
    page.get_by_label(re.compile(r"subject", re.IGNORECASE)).fill(subject)
    page.get_by_label(re.compile(r"message", re.IGNORECASE)).fill(
        f"Message for {subject}"
    )


def submit_contact_form(page, name, subject):
    fill_contact_form(page, name, subject)
    page.get_by_role("button", name=re.compile(r"submit|send", re.IGNORECASE)).click()


def login_as_admin(page):
    page.goto(f"{BASE_URL.rstrip('/')}{ADMIN_PATH}")
    page.get_by_label(re.compile(r"username", re.IGNORECASE)).fill(ADMIN_USERNAME)
    page.get_by_label(re.compile(r"password", re.IGNORECASE)).fill(ADMIN_PASSWORD)
    page.get_by_role("button", name=re.compile(r"login|log in", re.IGNORECASE)).click()
    expect(page.get_by_role("link", name=re.compile(r"messages", re.IGNORECASE))).to_be_visible()


def read_messages_count(page):
    messages_item = page.get_by_role(
        "link", name=re.compile(r"messages", re.IGNORECASE)
    )
    expect(messages_item).to_be_visible()
    match = re.search(r"\d+", messages_item.inner_text())
    assert match is not None, "Não foi encontrado número no item Messages"
    return int(match.group(0))


def open_messages(page):
    page.goto(f"{BASE_URL.rstrip('/')}{MESSAGES_PATH}")
    expect(page.get_by_text(re.compile(r"messages", re.IGNORECASE)).first).to_be_visible()


def test_CT001_enviar_mensagem_valida_exibe_confirmacao(page):
    name = unique_value("Visitor")
    subject = unique_value("Subject")

    submit_contact_form(page, name, subject)

    expect(page.get_by_text(f"Thanks for getting in touch {name}!", exact=True)).to_be_visible(
        timeout=REQUEST_TIMEOUT_MS
    )


def test_CT002_contador_aumenta_apos_envio_de_mensagem(page):
    login_as_admin(page)
    count_before = read_messages_count(page)

    page.goto(BASE_URL)
    name = unique_value("Visitor")
    subject = unique_value("Subject")
    submit_contact_form(page, name, subject)
    expect(page.get_by_text(f"Thanks for getting in touch {name}!", exact=True)).to_be_visible(
        timeout=REQUEST_TIMEOUT_MS
    )

    login_as_admin(page)
    count_after = read_messages_count(page)
    assert count_after == count_before + 1


def test_CT003_mensagem_enviada_aparece_na_caixa_de_mensagens(page):
    name = unique_value("Visitor")
    subject = unique_value("Subject")
    submit_contact_form(page, name, subject)
    expect(page.get_by_text(f"Thanks for getting in touch {name}!", exact=True)).to_be_visible(
        timeout=REQUEST_TIMEOUT_MS
    )

    login_as_admin(page)
    open_messages(page)

    expect(page.get_by_text(name, exact=True)).to_be_visible(timeout=REQUEST_TIMEOUT_MS)
    expect(page.get_by_text(subject, exact=True)).to_be_visible(timeout=REQUEST_TIMEOUT_MS)


def test_CT004_caixa_de_mensagens_solicita_login_apos_logout(page):
    login_as_admin(page)

    page.goto(f"{BASE_URL.rstrip('/')}{LOGOUT_PATH}")
    page.goto(f"{BASE_URL.rstrip('/')}{MESSAGES_PATH}")

    expect(page.get_by_label(re.compile(r"username", re.IGNORECASE))).to_be_visible(
        timeout=REQUEST_TIMEOUT_MS
    )
    expect(page.get_by_label(re.compile(r"password", re.IGNORECASE))).to_be_visible(
        timeout=REQUEST_TIMEOUT_MS
    )
```

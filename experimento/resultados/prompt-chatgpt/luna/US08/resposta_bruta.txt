CASOS DE TESTE

| ID | título | tipo | critério de aceitação relacionado | passos resumidos | resultado esperado |
|---|---|---|---|---|---|
| CT001 | Autenticar com credenciais válidas | positivo | CA01 | Enviar usuário e senha de demonstração ao endpoint de autenticação. | HTTP 200 e token não vazio. |
| CT002 | Rejeitar credenciais inválidas | negativo | CA02 | Solicitar autenticação com senha incorreta. | Resposta sem token e com motivo `Bad credentials`. |
| CT003 | Atualizar todos os dados da reserva | positivo | CA03 | Criar uma reserva; autenticá-la; enviar atualização completa com nome e preço novos; consultar a reserva. | HTTP 200 e resposta com os novos valores. |
| CT004 | Atualizar apenas o sobrenome | positivo | CA04 | Criar uma reserva; guardar os campos atuais; enviar PATCH somente com sobrenome novo; consultar a reserva. | HTTP 200, sobrenome alterado e demais campos preservados. |
| CT005 | Recusar atualização sem token | negativo | CA05 | Criar uma reserva e enviar atualização completa sem autenticação. | HTTP 403. |
| CT006 | Recusar atualização completa sem campos obrigatórios | negativo | CA06 | Criar uma reserva; autenticá-la; enviar PUT sem o campo `firstname`. | HTTP 400. |

SUPOSIÇÕES

1. Os seis critérios apresentados não possuem identificadores próprios. A correspondência é CA01 a CA06, na ordem em que aparecem na User Story.
2. O sistema é a API REST do Restful Booker. As rotas inferidas são `POST /auth`, `POST /booking`, `GET /booking/{id}`, `PUT /booking/{id}` e `PATCH /booking/{id}`. Os testes usam JSON e timeout de 15 segundos.
3. O login usa `{"username": ..., "password": ...}`. A autenticação válida retorna `{"token": "..."}`; a inválida retorna JSON contendo `reason: "Bad credentials"` sem token. O token é enviado no cabeçalho `Cookie` como `token=<valor>`.
4. A atualização completa usa PUT e exige `firstname`, `lastname`, `totalprice`, `depositpaid`, `bookingdates` e `additionalneeds`. A parcial usa PATCH. Essas estruturas e o formato do cabeçalho são inferidos para automatizar os critérios.
5. Para CT003–CT006, cada teste cria uma reserva própria usando valores concretos; o serviço deve permitir criar, atualizar e consultar reservas. A limpeza tenta excluir a reserva criada usando o token de administrador. A exclusão via `DELETE /booking/{id}` é uma suposição de preparação e limpeza.
6. CT002 usa uma senha incorreta derivada das credenciais fornecidas. Pressupõe que a API represente a rejeição com o motivo especificado no critério.
7. CT006 omite `firstname` para representar campos obrigatórios ausentes. O critério não define quais campos devem faltar; a resposta HTTP 400 para essa omissão é uma dedução necessária.
8. CT005 verifica a ausência de token usando PUT com atualização completa, para isolar a condição de autenticação. Pressupõe que a API responda HTTP 403 nesse caso.
9. Não há cenários de borda adicionais fundamentados no texto: os critérios não especificam limites de valores, formatos extremos ou comportamento de fronteira. A categoria borda, portanto, não se aplica.
10. A URL base é a informada na User Story. Os endpoints, cabeçalhos, corpos e respostas inferidos podem exigir ajustes antes de funcionarem contra o sistema real; o arquivo executável não comprova compatibilidade.

```python
import requests
import pytest


BASE_URL = "https://restful-booker.herokuapp.com"
TIMEOUT_SECONDS = 15

ADMIN_USERNAME = "admin"
ADMIN_PASSWORD = "password123"

BOOKING_TEMPLATE = {
    "firstname": "Casey",
    "lastname": "Original",
    "totalprice": 120,
    "depositpaid": True,
    "bookingdates": {
        "checkin": "2027-05-10",
        "checkout": "2027-05-15",
    },
    "additionalneeds": "Breakfast",
}


def authenticate(username=ADMIN_USERNAME, password=ADMIN_PASSWORD):
    return requests.post(
        f"{BASE_URL}/auth",
        json={"username": username, "password": password},
        timeout=TIMEOUT_SECONDS,
    )


def create_booking():
    response = requests.post(
        f"{BASE_URL}/booking",
        json=BOOKING_TEMPLATE,
        timeout=TIMEOUT_SECONDS,
    )
    assert response.status_code == 200, (
        f"Reserva de preparação não criada: HTTP {response.status_code}, "
        f"corpo: {response.text}"
    )
    booking_id = response.json()["bookingid"]
    assert booking_id
    return booking_id


def get_booking(booking_id):
    response = requests.get(
        f"{BASE_URL}/booking/{booking_id}",
        timeout=TIMEOUT_SECONDS,
    )
    assert response.status_code == 200, (
        f"Não foi possível consultar reserva {booking_id}: "
        f"HTTP {response.status_code}, corpo: {response.text}"
    )
    return response.json()


def admin_cookie():
    response = authenticate()
    assert response.status_code == 200, (
        f"Falha ao obter token para preparação: HTTP {response.status_code}, "
        f"corpo: {response.text}"
    )
    token = response.json().get("token")
    assert isinstance(token, str) and token
    return {"Cookie": f"token={token}"}


def delete_booking(booking_id, headers):
    response = requests.delete(
        f"{BASE_URL}/booking/{booking_id}",
        headers=headers,
        timeout=TIMEOUT_SECONDS,
    )
    assert response.status_code in (200, 201), (
        f"Falha ao remover reserva de teste {booking_id}: "
        f"HTTP {response.status_code}, corpo: {response.text}"
    )


def test_CT001_autenticar_com_credenciais_validas():
    response = authenticate()

    assert response.status_code == 200
    body = response.json()
    assert isinstance(body.get("token"), str)
    assert body["token"].strip()


def test_CT002_rejeitar_credenciais_invalidas():
    response = authenticate(password="senha_incorreta")

    body = response.json()
    assert "token" not in body
    assert body.get("reason") == "Bad credentials"


def test_CT003_atualizar_todos_os_dados_da_reserva():
    booking_id = create_booking()
    headers = admin_cookie()
    updated_booking = {
        "firstname": "Jordan",
        "lastname": "Updated",
        "totalprice": 345,
        "depositpaid": False,
        "bookingdates": {
            "checkin": "2027-06-01",
            "checkout": "2027-06-08",
        },
        "additionalneeds": "Late checkout",
    }

    try:
        response = requests.put(
            f"{BASE_URL}/booking/{booking_id}",
            json=updated_booking,
            headers=headers,
            timeout=TIMEOUT_SECONDS,
        )

        assert response.status_code == 200
        assert response.json()["firstname"] == updated_booking["firstname"]
        assert response.json()["totalprice"] == updated_booking["totalprice"]

        stored_booking = get_booking(booking_id)
        assert stored_booking["firstname"] == updated_booking["firstname"]
        assert stored_booking["totalprice"] == updated_booking["totalprice"]
    finally:
        delete_booking(booking_id, headers)


def test_CT004_atualizar_apenas_o_sobrenome():
    booking_id = create_booking()
    headers = admin_cookie()
    before = get_booking(booking_id)
    new_lastname = "Changed"

    try:
        response = requests.patch(
            f"{BASE_URL}/booking/{booking_id}",
            json={"lastname": new_lastname},
            headers=headers,
            timeout=TIMEOUT_SECONDS,
        )

        assert response.status_code == 200
        assert response.json()["lastname"] == new_lastname

        after = get_booking(booking_id)
        assert after["lastname"] == new_lastname
        for field in ("firstname", "totalprice", "depositpaid", "bookingdates", "additionalneeds"):
            assert after[field] == before[field]
    finally:
        delete_booking(booking_id, headers)


def test_CT005_recusar_atualizacao_sem_token():
    booking_id = create_booking()
    cleanup_headers = admin_cookie()

    try:
        response = requests.put(
            f"{BASE_URL}/booking/{booking_id}",
            json=BOOKING_TEMPLATE,
            timeout=TIMEOUT_SECONDS,
        )

        assert response.status_code == 403
    finally:
        delete_booking(booking_id, cleanup_headers)


def test_CT006_recusar_atualizacao_sem_campo_obrigatorio():
    booking_id = create_booking()
    headers = admin_cookie()
    incomplete_booking = {
        "lastname": "MissingFirstName",
        "totalprice": 250,
        "depositpaid": True,
        "bookingdates": {
            "checkin": "2027-07-01",
            "checkout": "2027-07-03",
        },
        "additionalneeds": "None",
    }

    try:
        response = requests.put(
            f"{BASE_URL}/booking/{booking_id}",
            json=incomplete_booking,
            headers=headers,
            timeout=TIMEOUT_SECONDS,
        )

        assert response.status_code == 400
    finally:
        delete_booking(booking_id, headers)
```

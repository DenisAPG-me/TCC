CASOS DE TESTE
| ID | título | tipo | critério de aceitação relacionado | passos resumidos | resultado esperado |
| CT001 | Exclusao sem token falha | negativo | CA01 | Criar reserva via API, tentar excluir sem enviar o cabeçalho de token de autenticação, e consultar a reserva criada. | Retorna status 403 na exclusão e status 200 na consulta subsequente da reserva. |
| CT002 | Exclusao com token invalido falha | negativo | CA02 | Criar reserva via API, tentar excluí-la enviando um token inválido no cabeçalho, e consultar a reserva. | Retorna status 403 na exclusão e a reserva continua existindo (status 200 na consulta). |
| CT003 | Exclusao com token valido sucede | positivo | CA03 | Obter token válido autenticando como admin, criar reserva via API, e excluí-la enviando o token válido. | Retorna status 201 ao excluir a reserva. |
| CT004 | Consulta de reserva excluida retorna nao encontrada | positivo | CA04 | Criar reserva, obter token válido, excluí-la, e tentar consultá-la pelo ID. | Retorna status 404 ao consultar a reserva excluída. |
| CT005 | Exclusao repetida de reserva retorna erro 4xx | negativo | CA05 | Criar reserva, obter token, excluir a reserva com sucesso, e tentar excluí-la novamente com o mesmo token válido. | Retorna status de erro 4xx na segunda exclusão. |
| CT006 | Listagem por filtro apos exclusao retorna vazio | borda | CA06 | Criar reserva com nome único específico, obter token, excluir a reserva, e listar/filtrar reservas pelo nome único. | A lista retornada para o filtro do nome único está vazia. |

SUPOSIÇÕES
1. A API sob teste é a Restful Booker pública (https://restful-booker.herokuapp.com), cujos endpoints padrão são `/auth` para obtenção de token, `/booking` para criação e listagem de reservas, e `/booking/{id}` para consulta, atualização e exclusão.
2. A autenticação é realizada enviando uma requisição POST para `{BASE_URL}/auth` com o JSON contendo as credenciais de demonstração `{"username": "admin", "password": "password123"}`, retornando um objeto JSON com o token no formato `{"token": "..."}`.
3. A exclusão de uma reserva é feita por meio de uma requisição DELETE para `{BASE_URL}/booking/{id}`, exigindo o cabeçalho `Cookie: token={token}` (conforme o padrão da API Restful Booker).
4. A ausência de token ou o envio de um token inválido na exclusão é simulada enviando o método DELETE sem o cabeçalho de cookie ou com um token fictício (ex: `token=invalidtoken123`), resultando no código HTTP 403 Forbidden especificado nos critérios CA01 e CA02.
5. Conforme o critério CA03, a resposta esperada para exclusão bem-sucedida é o status HTTP 201 Created (conforme especificado explicitamente na User Story).
6. A criação de uma reserva prévia para os testes é realizada via requisição POST em `{BASE_URL}/booking` enviando um payload JSON válido com dados de exemplo (ex: `firstname`, `lastname`, `totalprice`, `depositpaid`, `bookingdates`, `additionalneeds`), garantindo um nome único para o teste de listagem (CT006).
7. O filtro por nome único no endpoint de listagem (CA06) é realizado utilizando o parâmetro de query string `firstname` (ex: `{BASE_URL}/booking?firstname=UniqueName...`), onde a API retorna uma lista de IDs de reservas correspondentes. Após a exclusão, essa lista deve ser vazia ou não conter o ID excluído.
8. Como a User Story exige exclusivamente testes de API REST (conforme demonstrado pelos critérios baseados em endpoints, tokens, status HTTP e rotas), não há requisitos de testes de interface web (UI / Playwright), justificando a ausência de testes de UI e cumprindo a regra de cobrir todos os critérios de aceitação.

```python
import pytest
import requests

BASE_URL = "https://restful-booker.herokuapp.com"
TIMEOUT = 10
ADMIN_USER = "admin"
ADMIN_PASS = "password123"


def get_auth_token():
    response = requests.post(
        f"{BASE_URL}/auth",
        json={"username": ADMIN_USER, "password": ADMIN_PASS},
        timeout=TIMEOUT,
    )
    assert response.status_code == 200
    return response.json().get("token")


def create_test_booking(firstname="TestFirst", lastname="TestLast"):
    payload = {
        "firstname": firstname,
        "lastname": lastname,
        "totalprice1": 111,  # Note: restful-booker expects totalprice
        "totalprice": 111,
        "depositpaid": True,
        "bookingdates": {"checkin": "2026-01-01", "checkout": "2026-01-02"},
        "additionalneeds": "Breakfast",
    }
    response = requests.post(
        f"{BASE_URL}/booking", json=payload, timeout=TIMEOUT
    )
    assert response.status_code == 200
    data = response.json()
    return data["bookingid"]


def test_CT001_exclusao_sem_token_falha():
    booking_id = create_test_booking(
        firstname="NoToken", lastname="Booking"
    )

    # Tenta excluir sem token
    delete_response = requests.delete(
        f"{BASE_URL}/booking/{booking_id}", timeout=TIMEOUT
    )
    assert delete_response.status_code == 403

    # Verifica se a reserva continua consultável com status 200
    get_response = requests.get(
        f"{BASE_URL}/booking/{booking_id}", timeout=TIMEOUT
    )
    assert get_response.status_code == 200


def test_CT002_exclusao_com_token_invalido_falha():
    booking_id = create_test_booking(
        firstname="InvalidToken", lastname="Booking"
    )

    # Tenta excluir com token inválido
    cookies = {"token": "invalidtoken123"}
    delete_response = requests.delete(
        f"{BASE_URL}/booking/{booking_id}", cookies=cookies, timeout=TIMEOUT
    )
    assert delete_response.status_code == 403

    # Verifica se a reserva continua existindo
    get_response = requests.get(
        f"{BASE_URL}/booking/{booking_id}", timeout=TIMEOUT
    )
    assert get_response.status_code == 200


def test_CT003_exclusao_com_token_valido_sucede():
    token = get_auth_token()
    booking_id = create_test_booking(
        firstname="ValidToken", lastname="Booking"
    )

    cookies = {"token": token}
    delete_response = requests.delete(
        f"{BASE_URL}/booking/{booking_id}", cookies=cookies, timeout=TIMEOUT
    )
    assert delete_response.status_code == 201


def test_CT004_consulta_de_reserva_excluida_retorna_nao_encontrada():
    token = get_auth_token()
    booking_id = create_test_booking(
        firstname="DeletedCheck", lastname="Booking"
    )

    cookies = {"token": token}
    delete_response = requests.delete(
        f"{BASE_URL}/booking/{booking_id}", cookies=cookies, timeout=TIMEOUT
    )
    assert delete_response.status_code == 201

    get_response = requests.get(
        f"{BASE_URL}/booking/{booking_id}", timeout=TIMEOUT
    )
    assert get_response.status_code == 404


def test_CT005_exclusao_repetida_de_reserva_retorna_erro_4xx():
    token = get_auth_token()
    booking_id = create_test_booking(
        firstname="DoubleDelete", lastname="Booking"
    )

    cookies = {"token": token}
    delete_response_first = requests.delete(
        f"{BASE_URL}/booking/{booking_id}", cookies=cookies, timeout=TIMEOUT
    )
    assert delete_response_first.status_code == 201

    delete_response_second = requests.delete(
        f"{BASE_URL}/booking/{booking_id}", cookies=cookies, timeout=TIMEOUT
    )
    assert 400 <= delete_response_second.status_code < 500


def test_CT006_listagem_por_filtro_apos_exclusao_retorna_vazio():
    unique_name = "UniqueTargetName12345"
    token = get_auth_token()
    booking_id = create_test_booking(
        firstname=unique_name, lastname="FilterTest"
    )

    cookies = {"token": token}
    delete_response = requests.delete(
        f"{BASE_URL}/booking/{booking_id}", cookies=cookies, timeout=TIMEOUT
    )
    assert delete_response.status_code == 201

    list_response = requests.get(
        f"{BASE_URL}/booking", params={"firstname": unique_name}, timeout=TIMEOUT
    )
    assert list_response.status_code == 200
    bookings = list_response.json()
    assert len(bookings) == 0
```
